# 동향 보고

**필수 입력:** 동향 질문, 시간·지역·주제 범위, 공개·제공된 근거 자료

**기대 출력:** 근거가 연결된 동향 요약, 변화 신호, 과제 관련성, 불확실성 보고

**절차**

1. 보고서의 기준 시점과 포함·제외할 동향 범위를 정한다.
2. 자료를 주제와 시간 순으로 묶고 각 변화 신호에 출처와 날짜를 붙인다.
3. 여러 자료에서 일치하는 관찰과 서로 다른 해석을 나눠 기록한다.
4. 과제에 미치는 가능한 의미와 추가 확인 질문을 결론과 분리해 쓴다.

**완료·한계:** 범위 안의 신호와 출처·공백을 읽을 수 있게 정리하면 완료하며, 자료만으로 미래 동향이나 시장 방향을 확정하지 않는다.
