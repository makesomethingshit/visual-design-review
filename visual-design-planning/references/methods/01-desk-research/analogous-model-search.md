# 유사 모델 탐색

**필수 입력:** 해결하려는 문제, 유사성 판단 기준, 탐색할 공개·제공 자료

**기대 출력:** 유사 모델별 구조·작동 방식·차이·전이 조건을 비교한 목록

**절차**

1. 표면적 업종이 아니라 비교할 기능·관계·제약을 기준으로 유사성을 정의한다.
2. 공개·제공 자료에서 후보 모델의 실제 설명과 적용 맥락을 수집한다.
3. 후보마다 공통 구조, 차이점, 확인되지 않은 전제와 출처를 기록한다.
4. 현재 과제에 참고할 수 있는 부분과 그대로 옮길 수 없는 조건을 구분한다.

**완료·한계:** 기준에 따라 후보를 비교하고 전이 조건을 남기면 완료하며, 유사성이 효과나 적용 가능성을 증명하지 않는다.
