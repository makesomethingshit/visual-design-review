# 사용자 집단 정의

**필수 입력:** 기존 기록의 대상·상황·행동·요구 차이, 집단화 질문, 자료 ID·출처·시점

**기대 출력:** 근거 기반 집단 프로필, 구분 기준·대표 기록·경계 사례·적용 범위

**절차**

1. 기록에서 확인 가능한 구분 변수만 추출하고 성별·연령 등 미제공 속성을 추정하지 않는다.
2. 상황·행동·목표·제약의 반복 차이로 임시 집단을 만들고 각 기준에 근거 ID를 붙인다.
3. 집단마다 대표 기록과 경계·중복·반례를 작성하고, 한 기록이 여러 집단에 속할 수 있음을 표시한다.
4. 집단 정의가 과제 질문에 필요한지 대조해 적용 가능한 범위와 자료 공백을 함께 회신한다.

**완료·한계:** 각 집단과 미분류·복수 소속·근거 부족 항목을 빠짐없이 표시한다; 이는 기존 기록의 분석적 구분이며 모집단의 통계적 세분화나 대표성 검증이 아니고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
