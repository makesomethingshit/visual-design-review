# 핵심 통찰 정리

**필수 입력:** 분석 결과·근거 기록, 과제 질문·완료 기준, 주장별 출처·위치·시점

**기대 출력:** 핵심 통찰 목록과 근거·영향·한계·미확인 상태가 연결된 검토용 요약

**절차**

1. 기존 분석에서 과제 질문에 직접 답하는 관찰과 해석을 후보 통찰로 수집한다.
2. 각 후보를 `무엇이 보였나 → 왜 중요한가 → 어떤 자료가 받치나`로 다시 쓰고 근거 ID를 연결한다.
3. 중복 후보를 합치되 서로 다른 해석·반례·자료 충돌은 삭제하지 않고 별도 상태로 남긴다.
4. 완료 기준별로 충족·부분 충족·미확인·불충족을 표시하고, 사람의 판단이 필요한 선택을 통찰과 분리한다.

**완료·한계:** 핵심으로 채택하지 않은 후보와 미확인 항목도 목록에 남긴다; 통찰은 기존 근거의 요약·추론이며 디자인 방향의 승인이나 학술적 검증이 아니고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
