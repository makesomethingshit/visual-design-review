# 사용자 반응 분석

**필수 입력:** 기존 사용자 반응·피드백·리뷰·테스트 기록, 대상·상황·시점·원문 위치, 분석 질문

**기대 출력:** 반응 유형·대상 요소·맥락별 패턴, 대표·반대 사례와 해석 한계

**절차**

1. 반응을 대상 요소, 발화·행동, 상황, 기록 시점으로 분해하고 관찰 사실과 평가를 구분한다.
2. 반응 유형을 질문에 맞게 코드화해 긍정·부정·중립·혼합·판정 불가를 구별한다.
3. 같은 반응이 나온 맥락과 다른 반응이 나온 맥락을 비교하고, 대표성 없는 소수 기록은 그 범위를 명시한다.
4. 각 패턴을 원문·관찰 ID에 연결해 기대 효과, 실제 기록, 미확인 원인을 별도 문장으로 보고한다.

**완료·한계:** 분석 대상 반응과 제외·판정 불가 사례를 모두 표시한다; 기존 반응의 해석이며 감정의 원인, 태도 변화, 전체 사용자 선호를 추정해 확정하지 않고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
