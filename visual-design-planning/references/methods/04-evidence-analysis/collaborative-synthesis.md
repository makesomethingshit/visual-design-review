# 협업적 종합

**필수 입력:** 여러 분석자의 기존 메모·결과, 공통 과제 질문·완료 기준, 주장·근거 ID·원문 위치

**기대 출력:** 통합 주장표, 합의·불일치·미해결 항목, 원 기여와 근거가 보존된 종합 결과

**절차**

1. 결과를 동일한 주장·근거·상태 형식으로 정규화하고, 각 기여자와 원본 위치를 보존한다.
2. 같은 주장을 지지하는 결과와 서로 다른 범위의 결과를 구분해 통합 후보를 만든다.
3. 충돌은 한쪽을 임의로 제거하지 않고 주장·자료 시점·대상·분석 범위의 차이를 표로 비교한다.
4. 합의·부분 합의·미합의로 상태를 정하고, 과제 질문별 근거와 사람에게 남길 판단을 분리한다.

**완료·한계:** 모든 기여와 충돌·누락을 추적 가능하게 남긴다; 협업적 종합은 합의된 결론을 자동으로 진실이나 우선순위로 승격하지 않으며 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
