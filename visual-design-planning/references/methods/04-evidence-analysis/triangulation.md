# 삼각검증

**필수 입력:** 같은 질문을 다루는 서로 다른 기존 자료·방법·대상 기록, 각 근거의 출처·시점·범위

**기대 출력:** 주장별 근거 수렴·부분 수렴·불일치 표와 자료별 한계·추가 확인 조건

## 절차

1. 검증할 주장을 한 문장으로 고정하고, 각 자료가 실제로 측정·기록한 범위를 분리한다.
2. 자료 유형·출처·대상·시점별 근거를 독립적으로 요약해 먼저 `주장 → 근거 ID`로 연결한다.
3. 서로 일치하는 내용, 범위가 달라 비교할 수 없는 내용, 직접 충돌하는 내용을 구분한다.
4. 수렴은 제한된 범위의 지지로만 기록하고, 불일치와 공백·반례·후속 확인 조건을 함께 보고한다.

**완료·한계:** 사용한 모든 자료와 비교 불가 사유를 남긴다; 서로 다른 기록의 일치가 원인·객관적 진실·학술적 검증을 보장하지 않고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
