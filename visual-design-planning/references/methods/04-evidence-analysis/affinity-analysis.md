# 친화도 분석

**필수 입력:** 분석 단위별 메모·관찰·인용, 과제 질문, 각 항목의 자료 ID·원문 위치

**기대 출력:** 항목-군집 매핑, 군집명·대표 근거·예외 목록, 미분류 항목과 추적 가능한 군집 근거

**절차**

1. 메모를 한 항목 한 의미가 되도록 분리하고 중복 복사본에는 원본 ID를 유지한다.
2. 의미가 가까운 항목을 임시 군집으로 묶고, 군집 경계가 되는 차이와 근거를 기록한다.
3. 각 군집에 관찰을 요약하는 이름을 붙이고 대표·반대·미확인 항목을 같은 군집표에 남긴다.
4. 군집명이나 통찰을 과제 질문과 대조해 `항목 ID → 군집 ID → 근거 위치`로 검토한다.

**완료·한계:** 모든 항목이 군집·미분류·제외 중 하나로 표시된다; 군집의 존재가 중요도나 원인, 사용자 집단의 비율을 증명하지 않으며 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
