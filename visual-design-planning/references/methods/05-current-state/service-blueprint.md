# 서비스 블루프린트

**필수 입력:** 기록에 드러난 사용자 단계, 접점, 대면 활동, 후방 활동, 지원 과정, 증거물
**기대 출력:** 사용자 행동과 전·후방 활동·지원 과정·증거물의 연결 및 근거를 정렬한 블루프린트

**절차**

- 사용자 단계와 접점을 위에서 아래로 두고 기록에 있는 순서와 범위를 고정한다.
- 전면 활동, 후방 활동, 지원 과정, 생성되는 증거물을 각각의 레인에 배치한다.
- 사용자가 보는 선과 내부 처리의 경계를 자료에 근거해 표시하고, 모르는 내부 과정은 빈칸으로 둔다.
- 인계·대기·실패 단서를 근거 위치와 함께 기록하되 원인은 가설로 남긴다.

완료/한계: 제공 기록을 서비스 흐름으로 재배열한 Level 1 모델이며 현장 운영이나 내부 과정을 검증하지 않는다.
