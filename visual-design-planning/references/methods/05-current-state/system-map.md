# 시스템 지도

**필수 입력:** 기록에 등장하는 행위자·조직·자원·채널·규칙·산출물과 연결 단서
**기대 출력:** 시스템 요소, 흐름, 의존 관계, 경계, 근거와 불확실성을 표시한 현재 상태 모델

**절차**

- 자료에서 반복되는 요소를 행위자, 자원, 규칙, 채널, 산출물로 분류한다.
- 요소 사이의 정보·자원·결정 흐름을 방향과 근거 위치를 붙여 연결한다.
- 공식 경계와 실제로 추론한 경계를 구분하고 누락된 외부 조건을 표시한다.
- 순환, 병목, 충돌을 관찰된 관계와 가능한 해석으로 나누어 별도 기록한다.

완료/한계: 제공 기록의 시스템 관계를 구조화한 모델이며 인과관계나 전체 시스템의 완전성을 확정하지 않는다.
