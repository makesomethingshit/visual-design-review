# 과업 분석

**필수 입력:** 기록된 과업 목표, 대상, 선행 조건, 하위 행동·결정, 입력·출력, 장애 단서
**기대 출력:** 과업 목표에서 하위 단계까지의 계층, 조건, 결과, 장애와 근거를 정리한 분석표

**절차**

- 과업의 시작 조건과 완료 결과를 원문에서 확인하고 목표 문장을 한 줄로 고정한다.
- 목표를 하위 과업·행동·결정으로 분해해 선행 조건과 필요한 입력을 연결한다.
- 각 단계의 산출물, 성공 신호, 중단·되돌림 단서를 기록과 추론으로 구분한다.
- 빠진 단계와 실제 실패 여부를 분리하고 확인이 필요한 질문을 남긴다.

완료/한계: 기록에 나타난 과업 구조의 초안이며 실제 수행 시간·성공률·사용성은 검증하지 않는다.
