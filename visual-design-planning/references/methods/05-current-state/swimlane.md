# 스윔레인

**필수 입력:** 기록된 업무·단계, 담당 역할, 인계·결정 지점, 산출물, 시간·순서 단서
**기대 출력:** 역할별 레인에 업무 흐름과 인계·결정·대기 지점을 정렬한 비교 가능한 흐름도

**절차**

- 자료에 등장하는 역할을 레인으로 만들고 역할명이 다른 경우 원문과 통합 근거를 남긴다.
- 업무와 결정을 시간 순서로 배치해 담당 레인에 놓고 산출물과 입력을 연결한다.
- 레인 사이 인계, 승인, 대기, 되돌림을 별도 기호로 표시한다.
- 기록에 없는 담당자·시간·다음 단계는 추정하지 않고 미상으로 표시한다.

완료/한계: 문서화된 역할과 흐름의 비교도이며 실제 책임·소요 시간·병목을 측정하지 않는다.
