# 사진 일지 조사

**필수 입력:** 기존 사진 일지 이미지, 캡션·작성 메모, 촬영일·상황, 이미지 식별자와 분석 질문.

**기대 출력:** 이미지에 나타난 대상·행동·환경의 패턴, 캡션과 시각 근거의 일치·차이, 공백.

**절차**

1. 사진·캡션·촬영 시점·상황 메모를 한 엔트리로 묶고 누락 메타데이터를 표시한다.
2. 이미지에서 직접 보이는 요소와 작성자가 붙인 의미·기억을 분리해 코딩한다.
3. 사례·시점·상황별 반복 대상, 변화, 제외된 맥락을 비교한다.
4. 해석을 이미지 ID와 캡션 위치에 연결하고 이미지가 보여 주지 않는 내용은 추정하지 않는다.

**자료 추적:** 결과에 이미지 파일명/ID·캡션·촬영일·원문 위치를 연결한다.

**누락·편향 메모:** 기록자가 선택한 순간과 프레임 안의 장면만 남는다. 촬영하지 않은 대상·사적 맥락을 부재로 단정하지 않고, 선별된 사진을 일상 전체로 일반화하지 않는다.
