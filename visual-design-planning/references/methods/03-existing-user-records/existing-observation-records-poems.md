# 기존 관찰 기록의 POEMS 분류

**필수 입력:** 기존 관찰 기록·사진·스케치·메모, 관찰 시점·장소·사건 ID, POEMS 범주 정의와 분석 질문.

**기대 출력:** People·Objects·Environments·Messages·Services별 근거 표, 범주 간 관계·공백·반복 패턴.

**절차**

1. 기록 단위를 관찰 시점·장소·사건별로 나누고 관찰 사실과 해석을 분리한다.
2. 각 근거를 People, Objects, Environments, Messages, Services 중 하나 이상에 배치하고 해당 없음·미상을 허용한다.
3. 범주 간 연결과 반복·예외를 사례·장소별로 비교한다.
4. 모든 분류를 원기록 문장·사진·타임코드에 연결하고 분류 근거가 없는 항목은 보류한다.

**자료 추적:** 결과에 관찰 기록 ID·장소/시점·페이지/타임코드와 POEMS 범주를 연결한다.

**누락·편향 메모:** 관찰자의 프레이밍과 기록 가능한 장면이 범주를 좌우한다. POEMS에 담기지 않은 관계·시간·감정은 누락으로 표시하고, 기록 밖 요소를 범주에 채워 넣지 않는다.
