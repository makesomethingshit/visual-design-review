# 온라인 민속지 기록 조사

**필수 입력:** 기존 커뮤니티 게시물·댓글·스크린샷·아카이브, 스레드 구조, 게시 시점·커뮤니티 맥락.

**기대 출력:** 온라인 규범·언어·문제 해결 관행과 변화 양상의 근거 연결 요약.

**절차**

1. 게시물·댓글의 스레드 관계와 게시 시점을 보존하고 작성자 표기를 비식별화한다.
2. 반복되는 표현, 규범, 갈등, 해결 전략을 맥락을 잃지 않게 코딩한다.
3. 커뮤니티·기간·스레드별 차이와 예외를 비교하고 삭제·수정 흔적을 표시한다.
4. 해석을 게시물/댓글 ID와 캡처·아카이브 위치에 연결해 요약한다.

**자료 추적:** 결과에 커뮤니티·스레드·게시물 ID와 게시 시점을 연결한다.

**누락·편향 메모:** 공개·활동적인 이용자와 남아 있는 게시물만 포착되며 삭제·비공개 대화는 공백이다. 온라인 발언을 전체 커뮤니티 구성원의 견해로 일반화하지 않는다.
