# 기존 웹 행동 데이터 분석

**필수 입력:** 기존 웹 분석 추출본·이벤트 로그, 이벤트 스키마·추적 범위, 기간·세그먼트 정의와 분석 질문.

**기대 출력:** 페이지·이벤트·퍼널·경로의 행동 패턴, 기간·세그먼트 차이, 추적 공백과 해석 한계.

**절차**

1. 이벤트 정의·기간·세션화 규칙·추적되지 않는 경로를 데이터와 함께 고정한다.
2. 중복·결측·비정상 이벤트를 표시하고 기록된 스키마 밖의 의미를 임의로 채우지 않는다.
3. 페이지·퍼널·경로를 세그먼트·기간별로 비교하고 이탈·전환의 위치를 찾는다.
4. 집계와 해석을 쿼리·추출 파일·이벤트/세션 ID 범위에 연결하고 의도는 별도 미확정으로 둔다.

**자료 추적:** 결과에 추출 일시·스키마 버전·쿼리/파일·이벤트 범위를 연결한다.

**누락·편향 메모:** 쿠키·기기·동의·추적 설정과 로그 손실이 사용자를 제한한다. 기록된 클릭을 의도로 해석하지 않고 추적되지 않은 행동을 이탈로 단정하지 않는다.
