# 탐방 기록 조사

**필수 입력:** 기존 탐방·방문 기록, 이동 경로·장소 메모, 사진·티켓·시간 정보, 탐방 목적.

**기대 출력:** 장소별 환경·접점·제약의 순서화된 비교, 기록 근거와 공백.

**절차**

1. 방문 순서와 장소·시간·동행·활동을 정렬하고 기록 범위를 표시한다.
2. 공간 단서, 안내·서비스 접점, 행동·문제를 각각 코딩한다.
3. 장소·시간대·방문 목적별 공통점과 차이를 비교하고 단일 사례를 구분한다.
4. 발견을 사진·메모·경로의 타임스탬프나 페이지에 연결하고 미기록 구간을 남긴다.

**자료 추적:** 장소 ID·방문 기록·사진/메모 페이지·타임스탬프를 결과에 연결한다.

**누락·편향 메모:** 선택된 장소·동선·방문 시간과 접근 가능한 구역이 표본을 제한한다. 방문하지 않은 장소나 다른 시간의 경험을 추정하지 않는다.
