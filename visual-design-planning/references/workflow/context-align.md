# 맥락 확인

1. 의뢰·첨부 자료에서 디자인 대상, 판단할 질문, 대상·매체, 이미 정해진 제약, 기대 출력을 뽑는다.
2. 인덱스를 훑어 어떤 종류의 결과가 가능한지 파악한다. 예를 들어 “가격을 봐줘”는 실제 지불가 비교인지 용량당 가격 비교인지에 따라 표의 행과 단위가 달라진다.
3. 기대 출력의 내용이나 비교 범위가 달라지는 질문만 묻는다. 사람이 요청에서 이미 명확히 확정한 항목은 그대로 기록한다. 답에 따라 과제가 달라지는 경우에는 기대 출력과 범위를 먼저 확인받는다.
4. 합의한 질문, 출력 형식과 필수 항목, 범위·시점, 사용할 자료, 판정할 수 없는 범위를 의뢰 기록에 남긴다. 이 정보가 확정되면 과제 분할로 넘어간다.
