# 맥락 확인

1. 의뢰·첨부 자료에서 디자인 대상, 판단할 질문, 대상·매체, 이미 정해진 제약, 기대 출력을 뽑는다. 이미 확인된 사실은 다시 묻지 않는다.
2. 인덱스를 훑어 어떤 종류의 결과가 가능한지 파악한다. 예를 들어 “가격을 봐줘”는 실제 지불가 비교인지 용량당 가격 비교인지에 따라 표의 행과 단위가 달라진다.
3. 다음 판단을 가장 크게 바꾸는 정성적 의도·우선순위·표현 선호를 **한 번에 하나씩** 묻는다. 질문 하나에 독립된 여러 항목을 묶지 않고, 답을 받은 뒤 현재 상태에 맞는 다음 질문을 고른다. 치수·형식·제작·접근성처럼 확인 가능한 정량 조건은 신뢰할 수 있는 기존 공개·제공 자료를 조사한다. 자료가 여는 조사·방법·조건 대안은 사실·추론·선택지로 구분해 기록하며, 시각·표현 방향 후보는 만들지 않는다.
4. 디자인 브리프를 목표·배경·대상·메시지·결과물·환경·필수조건·제약·일정·예산·판단기준·미확인 항목으로 정리한다. 각 값에는 사용자 확정, 제공·공개 자료의 기록, [추론], [추측] 또는 미확인 상태를 표시한다.
5. 질문·출력 형식과 필수 항목·범위·시점·사용할 자료·판정할 수 없는 범위를 실행 기록에 남긴다. 이 **중간 조건 합의**는 별도 승인·정지·채택 게이트가 아니다. 필요한 입력이 있으면 바로 과제 분할과 조사로 진행하고, 사용자가 명시한 최종 승인·채택만 레벨 1 종료와 인계의 사용자 결정으로 기다린다.
