페이지 유료 전환 퍼널 · 무엇부터 손댈 것인가

PROBLEM STATEMENT무료 체험을 시작·진행·종료하는 페이지 사용자가 판단 시점에 "언제 과금되는지, 체험이 언제 끝나는지, 끝나면 무엇이 남는지, 한 달에 얼마인지"를 알 수 없어 구독 판단에서 막힌다.

먼저 손댈 곳은 무료 체험의 끝(종료일 인지·종료 후 상태·월 기준 가격 비교)이고, 다음이 체험 시작의 카드 등록·과금 시점 안내다 — 사용성 녹취와 티켓 표본이 같은 지점을 가리킨다 [추론]. 다만 이벤트 로그로는 어느 단계가 가장 많이 새는지 가릴 수 없고(사용자 ID 없는 월별 집계), 말씀하신 2.4%는 제공 로그에서 재현되지 않으며(가입→구독 도달 수 비 17.2%), 개선이 4%에 닿을지도 이 자료로는 판정할 수 없다1 [측정/기록].

의뢰 유료 전환 퍼널 개선의 우선순위와 근거대상 가입~구독 판단 단계의 페이지 사용자조사 2026-11-27 · 제공 자료만(새 조사 없음)자료 Amplitude 집계 2025-05~10 · 사용성 녹취 12건 2025-11 · 티켓 표본 40/240 · 설문 표본 32/512 2025-03방법 웹 행동 데이터 분석 · 원격 조사 기록 검토 · 내용 분석 · 설문 검토 · 여정 지도 · 삼각검증 · HMW · 원칙 생성기준 브리프 brief-v1.md실행 경로 runs/page-funnel-01/

여정 지도

대상 집단 기록이 겹치는 구간은 '체험 시작 → 체험 종료 → 구독 결정'이고, 그 구간은 로그에 이벤트가 비어 있다

네 자료의 막힘을 한 흐름 위에 놓아 어디에 근거가 몰리고 어디가 비는지 보려고 그렸다. 단계 순서는 이벤트 정의와 과업 순서에서 가정했고, 근거 없는 칸은 채우지 않았다2,10.

이 그림이 말하는 것 사용성·티켓 두 독립 자료가 모두 기록을 가진 칸은 체험 시작, 체험 중, 체험 종료, 구독 결정이다 [추론] EV-03~EV-06, EV-11, EV-12. 그런데 로그에는 체험 시작 이벤트가 없어, 가장 근거가 몰린 구간의 규모를 지금은 잴 수 없다 [측정/기록]2.

03

핵심 인사이트

1

체험 종료는 사용자에게 '보이지 않는 마감'이다

사용성 참가자 12명 중 3명이 종료일·종료 알림을 찾지 못했고(P03은 설정을 네 번 오감, P09는 종료일을 캘린더에 직접 적겠다고 함), 체험 종료 후 미구독 3명 중 2명은 종료 뒤 서재가 남는지 몰랐다(P06은 앱을 닫음) [측정/기록]3,6. 티켓 표본 40건 중 3건은 종료 알림을 못 받았다고, 2건은 체험 기간 표기가 화면마다 다르다고 했다 [측정/기록]11. 구독 판단이 일어나야 할 순간에 판단 재료가 보이지 않는다 [추론] EV-03, EV-06, EV-11.

단, 참가자 10명 미만 하위집단(체험 종료 후 미구독 3명)에 기대며 관찰자 1명 기록이다. 티켓 본문 중복(EV-14)으로 3건이 독립 문의 3건인지 확인되지 않았다. 녹취(2025-11)는 14일 체험 이후 시점이다.

2

요금제가 '한 달에 얼마'로 비교되지 않는다

12명 중 5명이 월/연 요금을 한 달 기준으로 바로 환산하지 못하거나 화면마다 가격이 다르게 보인다고 했다(P12는 가격 화면을 세 번 되돌아감) [측정/기록]4. 티켓 표본에도 "화면에는 할인율만 보여요"라는 월/연 차이 문의가 3건 있다 [측정/기록]12.

단, 설문에서 '가격'을 가장 큰 망설임으로 고른 응답은 32건 중 4건으로 우세하지 않다(EV-16). 설문은 '비싸다'를, 녹취는 '비교할 수 없다'를 잰 것이라 서로 다른 구성이다. P09는 가격보다 "몇 권 읽을지 몰라서"라고 했다(반례). 실제 가격 화면 캡처가 없어 어느 화면의 표기인지 특정하지 못했다.

3

체험 시작 버튼 뒤의 카드 등록이 '언제 돈이 나가는가'라는 질문을 만든다

무료 사용자 6명 중 3명이 체험 시작 시 카드 등록, 과금 시점, 체험 중 해지 시 과금 여부를 물었다 [측정/기록]5. 티켓 표본 3건은 "체험 시작 버튼을 눌렀는데 카드 등록 화면에서 막혔다"고 했다 [측정/기록]11.

단, 로그에 체험 시작·카드 등록 이벤트가 없어 여기서 얼마나 빠지는지 잴 수 없다(EV-02). 카드 등록 자체를 없앨지는 사업 결정이며 이 자료의 범위 밖이다.

4

지금의 로그로는 '어느 단계부터'를 숫자로 정할 수 없고, 목표 지표의 정의부터 맞지 않는다

추출본은 사용자 ID 없는 월별 도달 수 집계이고, 가입→구독 도달 수 비는 17.2%로 말씀하신 2.4%와 맞지 않는다 [측정/기록]1. 월별 도달 수 비는 6개월 내내 ±0.1%p 안에서 같아 체험 기간 변경(08-01)과 수집 장애(07-15~18)가 보이지 않는다 [측정/기록]1,2.

단, 2.4%가 방문자·설치 등 이 추출본에 없는 분모를 쓴 값이라면 두 수치는 모순이 아니라 다른 지표다. 정의를 확인하기 전에는 '어느 단계가 가장 새는가'와 '4% 달성 가능성'을 판정할 수 없다.

5

동기화·검색 불만은 많지만, 전환 전 막힘으로서의 근거는 약하다

티켓 표본 40건 중 동기화 8건·검색 8건으로 가장 많은 범주에 속하지만 단계 정보가 없고 [측정/기록]13, 녹취의 동기화 막힘은 월 구독 3명에게서만 나왔다 [측정/기록]8. 전환 전 근거는 설문 Q6 '동기화 불안' 4/32뿐이다16.

단, 동기화가 전환에 영향을 주지 않는다고 배제할 수는 없다(체험 중 다기기 사용자의 기록이 없음). 유지·해지 관점에서는 별도 과제로 볼 근거가 충분하다.

디자인 원칙 생성

원칙은 녹취와 티켓이 함께 가리킨 막힘에서만 세웠다

원칙조건과 행동근거예외·충돌
P1 체험 상태는 찾으러 가지 않아도 보인다체험 중이면 남은 기간·종료일·종료 시 과금 여부를 사용자가 자주 머무는 화면에서 설정 진입 없이 확인할 수 있게 한다EV-03, EV-11구독자에게는 체험 표시를 보이지 않는다(P04 구독 중 체험 배너, EV-08). 노출 빈도는 운영·마케팅과 조율

검증과 남은 한계
  • 공개 연구·업계 자료는 사용자 지시("새로 조사하지 말고")에 따라 찾지 않았다. 대상 집단 1차 근거는 제공된 사용성 녹취(A)뿐이다.
  • 사용성 녹취는 요약·발화 발췌만 있고 관찰자 1명 기록이다. 하위집단이 3명 단위라 비율로 일반화하지 않는다.
  • 티켓·설문은 표본이며 추출 방식(무작위·층화)을 확인하지 못했다. 표본 수치를 전수 비율로 쓰지 않았다.
  • 네 자료의 시점이 다르다(설문 2025-03, 로그·티켓 2025-05~10, 녹취 2025-11). 같은 사용자 집단인지 확인되지 않았다.
  • 상충: 설문 Q6 '가격' 4/32 vs 녹취 요금제 비교 5/12 — 측정 구성(망설임 이유 vs 비교 가능성)이 달라 생긴 차이로 보이나 확인되지 않음 [추론] EV-04, EV-16.
  • 동기화·검색이 전환에 영향을 주지 않는다는 결론은 내리지 않았다(교란 요인 확인 불가 — 배제할 수 없음).
  • 자기 점검: 문제 정의·인사이트별 A·B 근거 있음 / 맞비교 수치 분모 동일 여부 확인 / 여정 빈칸 유지 / 재인용 없음 / 원인 배제 없음 / 상충은 남은 쟁점으로 / 새 조사 필요 지표는 레벨 1 밖으로 표시.
  • 보고서 검사: scripts/check_report.py 실행, 결과는 lead-state.md에 기록.

  • 내용 분석 → 독립된 자연 발생 기록으로 교차 확인 → 범주·본문 코드 빈도 → 총괄 직접 수행 → 완료(표본)

  • 여정 지도 → 근거가 몰리고 비는 구간 확인 → 단계×자료 근거 유무 SVG → 총괄 직접 수행 → 부분 완료
  • 삼각검증 → 주장별 수렴 판정 → 수렴표 → 총괄 직접 수행 → 완료
  • 어떻게 하면 질문·디자인 원칙 생성 → 재정의와 방향 → HMW 5개·원칙 5개·DIR 2개 → 총괄 직접 수행 → 완료
