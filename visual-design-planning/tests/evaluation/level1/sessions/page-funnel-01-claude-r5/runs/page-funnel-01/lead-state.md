## 방법 선택 이유·자료 충분성

- T-01: 카드 필수 입력(추출본·스키마·기간·세그먼트) 모두 있음. 사용자 단위 원장이 없어 코호트 퍼널은 산출 불가 → '도달 수 비'로만 보고
- T-02: 녹취 요약·진행자 가이드 메모·세션 ID·과업 있음. 녹화·채팅·기술 상태 없음 → 발화·관찰 요약 범위로 한정
- T-03: 본문 발췌·화면·범주 있음. 코드 규칙은 제공 category + 본문 단위 코드로 정의
- T-04: 문항지·코드북·응답 표본 있음. 표본 날짜·교차 구조 이상 발견 → 단변량 분포만 사용
- 시도 한도: 공개 자료 검색 0회(사용자 지시). 제공 자료 6개 파일 전수 열람

## 자기 점검 (analysis-standards §6)

- 문제 정의·인사이트마다 A·B 근거: 예(인사이트 1~3 A+B, 4 B, 5 A+B)
- 맞비교 수치의 분모·문항 동일: 채널 간 비교는 같은 단계 정의의 도달 수 비로만, 단계 간 순위 매기지 않음. UT(12명)·티켓(40건)·설문(32건) 수치는 나란히 두되 맞비교하지 않음
- 여정 칸의 대상 집단 근거: 근거 없는 칸은 '근거 없음'으로 비움, 구조는 '가정한 구조' 표시
- 재인용 추적: 재인용 수치 없음
- 대상 조건 1차 연구: 제공된 UT(A)가 대상 집단 1차 자료. 공개 연구는 사용자 지시로 미탐색
- 원인 배제: '동기화·검색은 전환 원인이 아니다'로 쓰지 않고 '전환 전 막힘으로서 근거가 약하다/배제할 수 없다'로 씀
- 출처 간 상충: 설문 Q6(가격 4/32) vs UT 가격 비교 5/12 → 측정 구성이 다름(망설임 이유 vs 비교 가능성)으로 설명, 남은 쟁점에 올림
- 새 조사가 필요한 지표: UT 재검증·코호트 이벤트 추가를 레벨 1 밖으로 표시
