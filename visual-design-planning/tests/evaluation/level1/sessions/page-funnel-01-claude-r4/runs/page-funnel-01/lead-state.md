- Q-01(대화 끝에 질문, 답 대기): 2.4%는 어떤 분자·분모·기간으로 계산한 값인가. 과제 분할은 이 답 없이 진행 가능(단계별 근거 정리는 산식과 독립)하지만, 목표 4%를 어느 단계 개선량으로 환산할지는 이 답이 바꾼다.

## 방법 선택 이유와 자료 충분성

- 퍼널: 웹 행동 데이터 카드의 필수 입력(추출본·스키마·기간·세그먼트) 있음. 사용자 단위 원장이 없어 경로·코호트 분석은 불가 → 단계 비만.
- 녹취: 진행자 동반 원격 카드. 가이드는 "세션 진행 메모" 수준만 있음, 녹화·전체 녹취 없음, 과업 버전 표기 없음 → 부분 충족.
- 티켓: 코드 규칙은 제공 category·screen 열을 사용(내용 분석). 표본 40/240.
- 설문: 코드북 있음. 표본 32/512. 무결성 문제로 재사용 범위를 '문항 구조 확인'까지로 제한.
- 웹 조사: 사용자 지시로 수행하지 않음(시도 0회, 한도 0).

## 자기 점검 (analysis-standards §6)

- 문제 정의·인사이트마다 A·B 근거: 충족(인사이트 1~4 모두 A 포함, 설문은 근거로 쓰지 않음)
- 맞비교 수치의 분모·문항 동일: 같은 정의의 단계 비끼리 채널 간 비교만 함. 같은 달 도달 수 비는 코호트 전환율이 아니라고 표시. 2.4%와 17.2%는 비교 불가로 표시
- 여정 칸의 근거: 가입·체험 시작 수치 칸은 "근거 없음"으로 비움
- 재인용 추적: 재인용 자료 없음(전부 제공 원자료)
- 대상 조건에 맞는 1차 연구: 비구독 사용자 9명 관찰(A)이 있음. 유입 채널별 관찰은 없음
- 원인 배제 결론: "가격이 원인이 아니다"는 쓰지 않음(배제할 수 없음으로 표기). 체험 기간 변경 효과도 "판단 불가"
- 출처 간 다른 결과: 설문(가격 망설임 4/32)과 녹취(가격 단위 혼동 5명)는 측정 대상이 달라 비교 불가로 남은 쟁점에 올림; EV-04 vs EV-02 충돌 남은 쟁점에 올림
