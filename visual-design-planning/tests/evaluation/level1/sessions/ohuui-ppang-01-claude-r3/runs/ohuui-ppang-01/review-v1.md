# 검토 결과 v1 (중간) — 무엇부터 정해야 하는가

- 기준 브리프: brief-v2.md
- 작성 시점: 2026-11-27
- 상태: 중간 검토. 근거(EV) 0건, 과제 6건 중 완료 0 · 부분 완료 1 · 대기 3 · 미수행 2. 채택 전이며 모든 DIR은 미채택.

## 답

[추론] 로고를 살릴지 새로 할지를 가장 먼저 정해야 합니다. 포스터 2장과 인스타 게시물에 모두 로고가 들어가고 외부 인쇄 기간도 12월 말 마감 안에 들어가야 하므로, 로고가 늦게 정해지면 다른 결과물이 모두 늦어집니다. 다만 이 판단을 내릴 근거인 지금 로고 파일과 로고가 쓰이는 곳의 자료가 아직 없습니다. 오후 손님이 줄어든 원인도 자료가 없어 판단할 수 없습니다. 둘 다 이 결론을 바꿀 수 있는 한계입니다.

- 합의한 질문("무엇부터 정해야 하는지"): 순서와 이유는 답함. 순서 1의 판단 근거는 미충족(T01 대기).
- 근거 위치: 모든 주장은 사용자 발화 또는 [추론]·[추측]. [측정/기록] 0건.
- 시각·표현 방향(문구·톤·색·서체·이미지·레이아웃) 후보는 만들지 않음. "요즘 감성으로 예쁘고 따뜻하게"는 레벨 2 몫으로 남김.
