## 방법 선택 이유·자료 충분성

- T1: 이벤트 추출본+스키마 노트가 카드 필수 입력과 일치. 세션화 규칙 대신 월 집계라 코호트 분석은 불가(부분 충족).
- T2: 진행자 동반 원격 세션이므로 해당 카드 선택. 필수 입력 중 '진행자 가이드'는 진행 메모 수준만 있고 원본·진행자 질문 기록이 없다 → 부분 충족으로 실행, 진행자 프레이밍 영향은 미확인으로 남김. 심층 인터뷰 카드는 과업 기반 세션이라 맞지 않아 제외.
- T3: 티켓 본문이 텍스트이고 코드 규칙(범주·화면)이 있으므로 내용 분석. 측면별 감성 분석은 질문(단계 위치)과 단위가 맞지 않아 제외.
- T4: 응답 데이터·코드북·기간이 있어 기존 설문 응답 조사 카드 충족. 설문 설계 감사(기존 설문 자료 검토)는 이번 질문에 필요 없어 제외.
- T5: 서로 다른 4종 자료가 같은 단계 문제를 다루므로 삼각검증.
- 시도 한도: 제공 파일 7개 전부 1회씩 열람. 새 자료 탐색 없음(사용자 지시). 웹 검색 0회.
