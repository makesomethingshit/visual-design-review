PROBLEM STATEMENT전시장에서 도록을 쓰는 관람객은 도판이 어느 방의 어떤 작품인지, 도록의 순서가 무엇을 기준으로 하는지 알 수 없을 때 막히고, 인쇄된 위치·재질 정보가 현장과 다를 때 또 막힌다.

지면 구조는 근거가 지지하는 공통 원칙, 곧 "도판·캡션·작품 목록(가능하면 벽 캡션까지)이 같은 작품 번호로 이어지고 지면 순서의 기준이 하나로 밝혀진다"는 원칙 위에서 순서 기준(전시 동선·작가·기획 서사) 셋 가운데 하나를 고르는 문제입니다 [추론]. 도판 크기 위계는 지금 자료로는 정할 수 없습니다. 위계의 기준(대표작 지정·작가 간 균형·전시장 비중)과 68점 파일 조건이 먼저 필요합니다 [추론]. 이 판단을 바꿀 수 있는 한계는 세 가지입니다. 문의 근거는 1,140건 가운데 표본 40건(고유 문장 8개)이고 어느 도록에 대한 문의인지 알 수 없습니다. 이번 전시의 배치와 벽 캡션 번호 체계는 아직 없습니다. 관람객을 직접 관찰한 A급 연구도 찾지 못했습니다 [측정/기록]16.

의뢰 기획전 도록 지면 구조·도판 크기 위계의 근거대상 전시장에서 도록으로 도판·캡션을 찾는 관람객조사 2026-11-27자료 제공 5종(도록 요약 3, 문의 표본 40, 메타데이터 표본 30) + 공개 3건방법 내용 분석·과업 분석·사례 연구·콘텐츠 감사·문헌 조사·삼각검증기준 브리프 brief-v1.md실행 경로 runs/catalog-2027-01/

문제 들여다보기

내용 분석 + 과업 분석

문의 기록은 '도록 → 전시장' 방향에서만 막힘을 보여 주고, 의뢰문이 말한 '전시장 → 도록' 방향은 기록이 0건이다

문의는 관람객이 남긴 원자료(B)라서 찾기 흐름의 막힘을 단계별로 놓는 데 썼습니다. 한계: 표본 40건이 고유 문장 8개의 5회 반복이고, 범주·월·채널 분포가 완전히 균등합니다. 답변 기록이 없고, 2026년 문의라 지난 도록 3종의 전시 기간과 겹치지 않습니다. 그래서 어느 도록에 대한 문의인지 알 수 없습니다16.

이 그림이 말하는 것 기록이 있는 칸은 F2~F6입니다. 도판의 순서 기준, 작품이 있는 방, 방 순서, 현장과의 대조, 캡션 내용에서 막힙니다 [측정/기록]1. 벽의 작품에서 도록의 쪽으로 찾아가는 흐름(R1~R3)은 문의에 나타나지 않습니다. 그 흐름에 문제가 없다는 뜻인지, 문의로 이어지지 않았을 뿐인지는 이 자료로 가를 수 없습니다 [추론].

핵심 인사이트

1

관람객이 막히는 곳은 도판 자체가 아니라 도판과 전시장 작품을 잇는 연결 정보다

찾기 흐름 문의 25/40건은 "어느 방 작품인지", "어느 방부터", "순서 기준이 뭔지", "적힌 방과 다르다"처럼 도판과 공간·순서를 잇는 정보를 묻습니다 [측정/기록]1. 도판 크기나 보기 어려움을 지적한 문의는 표본에 없습니다 [측정/기록]1.

단, 고유 문장은 5개뿐이고 표본 분포가 인위적으로 균등해서 빈도로 중요도를 매길 수 없습니다. 대상 도록도 모릅니다. 근거는 원자료 1종에 기대고 있습니다.

2

지면에 위치를 인쇄하면 현장과 어긋날 수 있다. 위치 표기는 배치가 확정되는 시점에 묶인다

"3관에 있다고 적힌 작품을 2관에서 봤습니다", "전시장 평면도에 없는 작품이 도록에 있습니다"(합 10/40)는, 위치와 평면도를 인쇄한 도록에서도 어긋남이 생겼다는 기록입니다 [측정/기록]1. 이번 일정은 입고 뒤 개막까지 32일이라, 그 사이 배치가 바뀌면 같은 일이 생길 수 있습니다 [추론]10.

단, 이번 전시의 배치 확정 시점은 모릅니다. 어긋남의 원인(배치 변경, 인쇄 오류, 표기 혼동)도 기록에 없어 어느 것도 배제할 수 없습니다.

3

같은 판형(A4·96면)의 선례에는 찾기 장치가 없고, 작가 수는 그 선례의 두 배를 넘는다

2024 도록(A4·96면)은 작가 5명을 작가별 장으로 나눴고 위치 표기·평면도가 없었습니다 [측정/기록]3. 찾기 장치(룸 번호·평면도·번호를 병기한 목록)는 2025 A5 도록에만 있습니다 [측정/기록]4. 이번 도록은 12명이라, 작가별 장을 그대로 따르면 장 표지·간지 몫이 늘어 찾기 장치에 쓸 면이 줄어듭니다 [추론]310.

단, 장 표지를 장마다 넣을지는 정해지지 않았고, 면 배분은 레벨 2에서 정합니다. 2025 찾기 장치의 효과를 보여 주는 기록은 없습니다.

  • 도록 요약은 PDF 기준이며 인쇄물 실측이 아님. 도판 합계와 작품 수가 맞지 않는 이유 미확인
  • 메타데이터 38점 미확인. 해상도·가로세로 정보가 없어 도판 단계 판정(T07) 불가
  • 공개 자료 충돌: 문의의 1관~3관 vs 기사의 4개 전시실, 같은 기관 여부 미확인
  • 자기 점검: 문제 정의·인사이트 모두 B 근거 있음(A 없음 명시). 분모가 다른 수치는 맞비교하지 않음. 과업 그림의 칸은 원문이 있는 칸만 채움. 원인 배제 결론 없음. 충돌은 남은 쟁점에 올림
적용한 방법
  • 내용 분석 + 과업 분석 → 문의를 찾기 단계에 배치 → 단계별 건수·원문 → 총괄 순차 수행 → 부분 완료
  • 사례 연구 → 같은 기관 선례의 전이 판정 → 3종 비교표 → 총괄 순차 수행 → 완료
  • 콘텐츠 목록·감사 → 캡션 원천 데이터 준비 상태 → 필드 점검표 → 총괄 순차 수행 → 부분 완료(30/68)
  • 문헌·기존자료 조사 → 정량 조건(캡션·제본) 확인 → 출처별 근거표 → 검색 7회·열기 5회 → 부분 완료
  • 삼각검증·디자인 원칙 생성·어떻게 하면 질문 → 취합 → 수렴표·원칙·HMW·DIR → 완료
  • 여정 지도: 이번 전시 배치 기록이 없어 쓰지 않음(T06 대기)
