# 구독 의향 설문 · 문항지와 코드북 (합성)

- 조사명: 페이지 구독 의향 조사
- 기간: 2025-03-02 ~ 2025-03-20
- 모집: 앱 내 배너, 무작위 노출. 응답 512건
- 표본 파일: `survey_responses_sample.csv` (무작위 32건)

## 문항

| ID | 문항 | 응답 형식 |
| --- | --- | --- |
| Q1 | 페이지를 얼마나 자주 쓰나요? | 1(거의 안 씀) ~ 5(매일) |
| Q2 | 앱을 알게 된 경로 | 코드 |
| Q3 | 무료 체험 기간이 충분했나요? | 1(매우 부족) ~ 5(충분) |
| Q4 | 가격이 적정하다고 느끼나요? | 1(매우 비쌈) ~ 5(매우 적정) |
| Q5 | 앞으로 구독할 의향이 있나요? | 1(전혀 없음) ~ 5(매우 있음) |
| Q6 | 구독을 망설이게 하는 가장 큰 이유 하나 | 코드, 해당 없으면 공백 |
| Q7 | 가장 원하는 기능 하나 | 코드 |
| Q8 | 자유 응답(선택) | 코드화된 짧은 문구, 없으면 공백 |

## 코드

Q2 `앱 알게 된 경로`: `지인 추천` / `앱스토어 검색` / `SNS 광고` / `블로그 리뷰`

Q6 `망설임 이유`: `가격` / `무료 책 부족` / `동기화 불안` / `읽을 시간 부족` / `결제 수단` / `기타`

Q7 `원하는 기능`: `필기` / `오프라인 저장` / `통계` / `추천`

Q8 `자유 응답 코드`: `가격이 부담` / `좋음` / `체험 길이` / `동기화` / `가격` / 그 외는 빈칸

## 응답 파일 열

`respondent_id, submitted_at, plan, Q1..Q8`

- `plan`은 응답 시점의 상태다: `무료` / `체험 종료` / `월 구독` / `연 구독`.
- 빈칸은 무응답이다. 0이나 '해당 없음'으로 바꾸어 채우지 않았다.
- Q8은 자유 응답을 코드화한 값이며 원문은 별도 보관 중이나 이 폴더에는 없다. 코드화 기준은 위 목록뿐이다.
- 응답자 속성(연령·성별·지역)은 수집하지 않았다.
