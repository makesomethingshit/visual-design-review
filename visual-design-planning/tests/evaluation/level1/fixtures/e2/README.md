# E2 제공 자료 · 구독형 독서 앱 '페이지'

브리프의 네 자료를 경량화한 표본이다. 전수 규모는 브리프와 같고(로그 6개월, 녹취 12건, 티켓 240건, 설문 512건), 이 폴더에는 표본과 자료 설명만 둔다.

| 파일 | 대응 자료 | 이 폴더의 범위 | 전수 |
| --- | --- | --- | --- |
| `amplitude_funnel_2025-05_2025-10.csv` | Amplitude 이벤트 추출본 | 2025-05~2025-10, 채널 4종 × 단계 4개월별 집계 (96행) | 같은 기간 전체 집계. 사용자 단위 원장은 미포함 |
| `amplitude_export_notes.md` | 위 추출본의 설정·정의 | 수집 조건, 단계 정의, 알려진 결측 | — |
| `usability_sessions_2025-11.md` | 사용성 테스트 녹취 12건 | 12건 전부, 세션별 요약과 발화 3~4개 | 12건 |
| `support_tickets_sample.csv` | 고객지원 티켓 240건 | 무작위 표본 40건 (본문 발췌) | 240건 |
| `survey_questionnaire_codebook.md` | 설문 문항지·코드북 | 문항 8개와 코드 | — |
| `survey_responses_sample.csv` | 설문 응답 512건 | 무작위 표본 32건 | 512건 |

## 자료별 한계 (실행 시 근거로 남길 것)

- 퍼널 파일은 **월·채널·단계별 사용자 수 집계**다. 사용자 ID가 없어 같은 사람이 여러 달에 걸쳐 이탈한 것인지, 매달 새로 들어온 사람인지 구분할 수 없다.
- 티켓·설문은 표본이다. 표본 비율을 전수 비율로 확정하려면 표본 추출 방식(무작위, 층화 여부)을 확인해야 하며, 이 폴더에는 추출 스크립트가 없다.
- 네 자료의 기간이 서로 다르다(로그 2025-05~10, 녹취 2025-11, 티켓 2025-05~10 표본, 설문 2025-03). 같은 시점의 사용자 집단인지 확인되지 않았다.
