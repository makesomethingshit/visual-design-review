# Amplitude 추출본 설정·정의 (합성)

## 추출 조건

| 항목 | 값 |
| --- | --- |
| 데이터셋 | 페이지 웹·앱 통합 이벤트 |
| 기간 | 2025-05-01 ~ 2025-10-31 (6개월) |
| 세그먼트 | 유입 채널(마지막 터치 기준) |
| 채널 값 | `organic_search`, `paid_social`, `referral`, `content_blog` |
| 집계 | 주 단위 사용자 수를 월 단위로 합산, 사용자 단위 원장 미포함 |
| 추출일 | 2026-02-18 |

## 단계 정의

| 단계 | 정의 |
| --- | --- |
| `signup` | 계정 생성 완료 |
| `first_book` | 가입 후 첫 책 열람(표지가 아닌 본문 1쪽 이상) |
| `trial_end` | 무료 체험 종료 시점 도달 |
| `subscribe` | 유료 구독 시작(첫 결제 성공) |

## 알려진 결측·변경

- **2025-08-01 무료 체험 기간 정의 변경**: 7일 → 14일. 8월 이후 `trial_end` 사용자 수는 같은 가입자 수라도 이전 달과 비교해 늦게 잡히고, 9월 `trial_end`에 8월 가입자가 일부 섞인다.
- 채널 값이 비어 있는 이벤트가 전체의 약 2%다. 이 추출본에서는 제외했다.
- 앱 내 웹뷰 결제는 `subscribe`에 포함되지만, 스토어 결제 취소·환불은 사후 이벤트로 기록되지 않는다.
- 2025-07-15 ~ 07-18 수집 파이프라인 장애로 해당 기간 사용자 수가 과소 집계됐다(운영 로그 기준).

## 파일 열 설명

`amplitude_funnel_2025-05_2025-10.csv`: `month, channel, step, users`

- `users`는 그 달에 해당 단계에 도달한 사용자 수다. 누적 잔존이 아니라 월별 도달 수이므로, 월 간 합을 총 가입자로 해석하지 않는다.
- 한 사용자가 같은 달에 여러 번 도달해도 1로 센다.
