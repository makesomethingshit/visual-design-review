# 레벨 1 평가용 샘플 자료

E2(자료가 이미 있는 서비스 개선)와 E3(인쇄물 기획) 실행에서 참조하는 경량 샘플 자료다. 모두 **합성 데이터**이며 실제 서비스·미술관·작품과 관계없다. E1은 제공 자료가 없는 브리프이므로 이 폴더를 쓰지 않는다.

## 실행 전 복사

각 케이스의 자료 폴더를 작업 폴더의 `materials/`로 복사한 뒤 실행한다. 파일을 작업 폴더 밖에 두면 세션이 읽을 수 없고, 그때는 [eval-cases.md](../../../eval-cases.md)의 '자료 미제공 분기'가 적용된다.

```bash
mkdir -p <작업 폴더>/materials
cp -R visual-design-planning/tests/evaluation/level1/fixtures/e2/* <작업 폴더>/materials/
cp -R visual-design-planning/tests/evaluation/level1/fixtures/e3/* <작업 폴더>/materials/
```

## 폴더

| 폴더 | 대상 케이스 | 내용 |
| --- | --- | --- |
| `e2/` | E2 · 구독형 독서 앱 '페이지' | 퍼널 집계 추출본, 사용성 테스트 녹취 12건, 지원 티켓 표본 40건, 설문 표본 32건과 문항지·코드북, 각 자료의 수집 범위·한계 |
| `e3/` | E3 · 서울사진미술관 기획전 도록 | 지난 도록 3종 지면 비교 요약, 관람객 문의 표본 40건, 아카이브 메타데이터 표본 30점 |

## 원칙

- 표본은 전수 자료의 일부다. 파일 안의 `rows`·`sample` 표기가 전수와 표본 수를 구분한다. 표본을 전수로 착각하고 비율을 확정하면 안 된다.
- 파일에 없는 값은 자료에 없는 값이다. 브리프에 적힌 전수 규모(티켓 240건, 문의 1,140건, 사진 68점 등)와 표본 수를 구분해 기록한다.
- 이 자료는 판정표의 정답을 담지 않는다. 관찰·인용·한계는 실행 세션이 직접 만들고, 판정은 사람이 [eval-cases.md](../../../eval-cases.md)로 한다.
