# 질문지

**필수 입력:** 조사 질문, 대상 참여자 조건, 응답 방식·분량 제약, 필요한 결정 정보

**기대 출력:** 목적에 연결된 질문 초안, 응답 형식·순서·분기, 검토가 필요한 표현 목록

**절차**

1. 결정에 필요한 정보를 문항별로 배정하고 중복 문항과 불필요한 호기심을 제거한다.
2. 한 문항에 한 주제만 묻도록 중립적인 표현과 응답 선택지를 작성한다.
3. 쉬운 질문에서 민감하거나 상세한 질문으로 순서를 정하고 조건부 분기를 표시한다.
4. 예상 응답 시간, 이해가 어려운 용어, 빠진 선택지를 표시해 사람이 검토하게 한다.

**완료·한계:** 질문지 초안과 검토 포인트를 만들면 완료하며, 파일럿·응답 수집·문항 타당성 검증은 포함하지 않는다.
