# 맥락 조사 계획

**필수 입력:** 디자인 과제·판단 질문, 대상·매체·제약, 사용 가능한 공개·제공 자료와 일정

**기대 출력:** 맥락 질문별 조사 방법, 자료원, 기대 결과, 범위·중단 기준을 담은 계획

**절차**

1. 브리프에서 이미 정해진 조건과 아직 확인해야 할 맥락 질문을 분리한다.
2. 질문마다 공개 자료 분석, 제공 기록 검토, 사람의 후속 조사 중 가능한 경로를 배정한다.
3. 필요한 입력·기대 출력·출처 기록 형식과 질문별 완료 조건을 적는다.
4. 자료 접근 불가, 신규 참여자 필요, 일정 부족 상황의 보류·대체 경로를 표시한다.

**완료·한계:** 질문과 실행 조건이 연결된 계획이면 완료하며, 계획 자체가 조사 수행이나 사용자 결과를 의미하지 않는다.
