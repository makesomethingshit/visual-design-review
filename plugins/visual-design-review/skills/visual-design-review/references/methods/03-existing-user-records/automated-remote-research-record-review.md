# 자동화 원격 조사 기록 조사

**필수 입력:** 기존 자동화 원격 조사 실행 로그·이벤트 데이터·결과 리포트, 스크립트/과업 버전, 표본 정의와 실행 기간.

**기대 출력:** 과업·이벤트 순서별 완료·중단·오류 패턴, 실행 조건과 데이터 공백.

**절차**

1. 실행 버전·과업 ID·이벤트 스키마와 기록된 성공·실패 기준을 정리한다.
2. 기존 로그에서 과업 순서, 오류, 소요시간, 중단을 동일한 단위로 집계한다.
3. 실행군·환경·기간별 차이와 비정상 기록을 비교하고 원인을 추정하지 않은 채 표시한다.
4. 집계값을 실행·과업·이벤트 ID와 연결하고 기록되지 않은 상태는 미상으로 남긴다.

**자료 추적:** 결과에 실행 ID·스크립트 버전·과업/이벤트 ID·로그 위치를 연결한다.

**누락·편향 메모:** 자동화가 포착하는 대리 지표와 기술적으로 기록된 사용자만 남는다. 봇·기기·네트워크 제외 규칙과 누락 이벤트가 결과를 치우칠 수 있으므로 실제 의도나 전체 사용자를 단정하지 않는다.
