# 경험 서술 자료 조사

**필수 입력:** 기존 경험 서술·회고문·음성 기록, 작성 맥락과 질문, 작성일·사례 ID.

**기대 출력:** 경험의 시간 흐름·의미 부여·감정·결정 전환에 대한 근거 연결 요약과 대안 해석.

**절차**

1. 서술을 사건 순서, 전환점, 평가·감정, 현재의 회고로 구분한다.
2. 직접 묘사된 사건과 서술자가 부여한 의미·원인을 분리해 코딩한다.
3. 사례·시점별 반복 서사와 상반된 서술을 비교하고 비어 있는 구간을 표시한다.
4. 요약 문장을 원문 문단·타임코드에 연결하고 사실·해석·기억의 층위를 보존한다.

**자료 추적:** 각 결과에 서술 자료 ID·작성일·문단/타임코드와 질문 맥락을 연결한다.

**누락·편향 메모:** 회고는 기억 재구성과 현재의 관점에 영향을 받는다. 말해지지 않은 경험을 없다고 보지 않으며, 설득력 있는 한 서사를 모든 사례의 전형으로 일반화하지 않는다.
