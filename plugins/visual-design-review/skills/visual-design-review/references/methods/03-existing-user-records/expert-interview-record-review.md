# 전문가 인터뷰 기록 조사

**필수 입력:** 기존 전문가 인터뷰 녹취·요약, 전문 영역·역할·경력 맥락, 세션 ID, 질문지 버전.

**기대 출력:** 전문적 판단·근거·조건의 목록, 사용자 기록과의 일치·충돌, 적용 범위와 공백.

**절차**

1. 전문가별 발화를 주장, 경험적 사례, 권고, 추정으로 구분해 코딩한다.
2. 각 권고의 전제·적용 조건·대상 범위를 기록하고 사용자 자료의 근거와 분리한다.
3. 전문가 간 및 기존 사용자 기록과의 일치·충돌을 비교한다.
4. 조건 없는 일반화를 제거하고 주장을 원발화 위치와 함께 제한적으로 요약한다.

**자료 추적:** 주장마다 전문가 세션 ID·역할·발화 타임코드를 연결한다.

**누락·편향 메모:** 초대된 전문가의 관점과 전문 분야가 표본을 결정한다. 전문가 의견을 사용자 경험의 직접 증거로 바꾸지 않고, 기록되지 않은 반대 견해는 미상으로 둔다.
