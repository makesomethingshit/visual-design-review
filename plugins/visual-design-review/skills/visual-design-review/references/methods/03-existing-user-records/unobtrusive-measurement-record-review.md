# 비개입 측정 기록 검토

**필수 입력:** 기존 센서·로그·측정 데이터, 변수·단위 정의, 수집 기간·맥락, 기록된 제외·결측 규칙.

**기대 출력:** 맥락별 측정값의 분포·변화·이상치와 데이터 품질 공백, 해석 가능한 범위.

**절차**

1. 변수 정의·단위·측정 창·기기 메타데이터와 기존 결측·제외 규칙을 정리한다.
2. 기록된 규칙만 적용해 결측·중복·이상 구간을 표시하고 임의 보정은 하지 않는다.
3. 기간·맥락·사례별 분포와 변화를 비교하며 측정값과 의미 해석을 분리한다.
4. 집계값을 원시 이벤트·측정 창·파일/행 ID에 연결하고 측정되지 않은 상태를 미상으로 둔다.

**자료 추적:** 결과에 변수명·단위·수집 창·원시 파일/행 또는 이벤트 ID를 연결한다.

**누락·편향 메모:** 측정값은 경험의 대리 지표이며 장비·센서·수집 조건의 영향을 받는다. 측정되지 않은 행동과 결측 구간을 0이나 부재로 간주하지 않는다.
