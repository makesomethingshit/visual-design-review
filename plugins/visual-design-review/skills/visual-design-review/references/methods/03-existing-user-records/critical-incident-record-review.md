# 중요 사건 기록 조사

**필수 입력:** 기존 중요 사건 보고서·회고·일지, 사건 전후 맥락, 영향·해결 기록, 사건 ID와 기록일.

**기대 출력:** 촉발 조건·대응·결과의 사건 흐름, 반복 위험·완화 방식·예외와 공백.

**절차**

1. 사건 전·중·후의 사실 기록과 사후 해석을 시간순으로 분리한다.
2. 촉발 조건, 사용자 대응, 시스템/환경 결과, 복구 단계를 공통 코드로 표시한다.
3. 성공·실패·미해결 사건과 빈도를 비교하고 단일 특이 사례를 구분한다.
4. 각 결론을 사건 ID·티켓·일지의 페이지/타임코드에 연결하고 미기록 원인을 추정하지 않는다.

**자료 추적:** 결과 항목에 사건 ID·기록일·원보고서 위치와 전후 단계 근거를 연결한다.

**누락·편향 메모:** 기억에 남는 심각한 사건과 보고된 사건이 과대표집될 수 있다. 평상시 문제나 보고되지 않은 사건을 없다고 보지 않으며, 사건 빈도를 전체 사용 경험의 빈도로 바꾸지 않는다.
