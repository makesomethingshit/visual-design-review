# 어떻게 하면 질문

**필수 입력:** 기록된 대상과 필요, 해결을 막는 조건, 바꾸고 싶은 결과, 범위·근거
**기대 출력:** 대상·필요·방향을 열어 둔 “어떻게 하면” 질문 후보와 범위·근거·검토 질문

## 절차

- 확인된 상황과 대상의 필요를 한 문장으로 분리하고 해결책 이름은 제거한다.
- “어떻게 하면 [대상]이 [필요한 변화]를 [조건 안에서] 할 수 있을까?” 형식의 후보를 만든다.
- 후보마다 너무 넓거나 좁은 표현, 기록 근거, 빠진 제약을 표시한다.
- 서로 다른 초점의 질문을 비교해 사람에게 선택·수정·보류를 요청한다.

완료/한계: 탐색을 여는 질문 후보이며 문제의 정답이나 해결책을 제시·확정하지 않는다.
