# 트렌드 매트릭스

**필수 입력:** 관찰할 주제·기간, 비교 축, 공개·제공된 동향 자료

**기대 출력:** 동향별 시점·영역·근거·관련성·불확실성을 비교하는 매트릭스

**절차**

1. 동향을 비교할 축과 시간 구간을 먼저 고정하고 서로 다른 의미의 항목을 분리한다.
2. 공개·제공 자료에서 동향 신호를 모아 출처와 관찰 날짜를 행마다 남긴다.
3. 같은 신호를 합치되, 자료가 말하지 않는 지속성·규모는 추정하지 않는다.
4. 과제와의 관련성 및 추가 확인 필요 여부를 별도 열로 표시한다.

**완료·한계:** 정한 축으로 비교 가능한 행과 공백을 채우면 완료하며, 매트릭스의 분류가 미래 예측이나 보편적 유행 판정은 아니다.
