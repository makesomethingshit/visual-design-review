# 사례 연구

**필수 입력:** 사례를 고를 질문·기준, 사례별 공개·제공 기록, 비교할 맥락

**기대 출력:** 사례별 맥락·행동·관찰 결과·근거·전이 주의를 담은 사례 카드와 비교 요약

**절차**

1. 질문에 필요한 사례 선정 기준과 사례 간 비교 단위를 정한다.
2. 공개·제공 기록에서 사례의 배경, 선택, 실행, 결과로 보고된 내용을 추출한다.
3. 보고된 사실과 자료 작성자의 해석, 현재 과제에서의 가설을 나눠 적는다.
4. 사례 간 공통점·차이와 맥락이 달라지는 지점을 비교한다.

**완료·한계:** 선정 기준과 근거가 붙은 사례 카드를 완성하면 완료하며, 사례 하나로 인과관계나 일반적 성공을 주장하지 않는다.
