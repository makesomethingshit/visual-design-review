# 권력 관계 지도

**필수 입력:** 제공 자료·공개 기록에서 확인 가능한 행위자, 결정 권한, 자원, 정보 접근, 관계 단서
**기대 출력:** 행위자별 권한·의존·영향 관계와 각 관계의 근거 위치를 표시한 현재 상태 지도

## 절차

- 자료마다 행위자와 조직을 고유 이름으로 추출하고 역할과 기록 위치를 붙인다.
- 결정권, 자원 통제, 정보 접근, 의존 관계를 사실 기록과 해석으로 나누어 연결한다.
- 연결마다 문서·날짜와 확실성 상태를 표시하고, 확인되지 않은 관계는 미상으로 둔다.
- 기록 간 충돌과 지도에서 제외된 행위자를 별도 목록으로 남긴다.

완료/한계: 기록된 권력 관계의 지도이며 실제 영향력이나 비공개 관계를 검증하지 않는다.
