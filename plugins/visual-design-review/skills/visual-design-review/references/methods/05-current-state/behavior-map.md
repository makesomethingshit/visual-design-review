# 행동 지도

**필수 입력:** 제공 자료·공개 기록의 관찰 행동, 상황·촉발 단서, 순서, 반복·차이, 결과
**기대 출력:** 상황별 행동 순서와 변형, 관찰 근거, 해석·미확인 상태를 구분한 행동 지도

## 절차

- 해석을 덧붙이기 전에 기록된 행동을 시간·상황·대상별로 그대로 적는다.
- 행동을 촉발 단서, 선택, 결과로 나누고 각 항목에 근거 위치를 붙인다.
- 반복되는 경로와 예외 경로를 분리하며 의도나 동기는 가설로만 표시한다.
- 기록의 표현과 지도에서 일반화한 표현을 대조해 과도한 일반화를 제거한다.

완료/한계: 확인 가능한 행동의 구조화이며 관찰되지 않은 행동 빈도나 동기를 추정해 확정하지 않는다.
