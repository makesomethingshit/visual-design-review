# 배정과 결과 형식

## 하위에 보내는 입력

하위가 배정 메시지만 읽어도 시작할 수 있게 다음 내용을 한 번에 보낸다. 총괄은 배정 직전에 지정 카드와 공유 근거를 직접 열어 현재 버전을 확인한다.

1. 과제 ID와 버전, 질문과 범위, 기대 결과물과 완료 기준을 적는다. 리서치에는 찾을 자료, 허용 출처, 검색 범위와 종료 조건도 적는다.
2. **방법 카드**에는 배포본에서 실제로 연 카드의 제목·상대 경로와 본문을 넣는다. 도구가 읽기 가능한 첨부를 받으면 그 카드만 첨부해도 된다. 카드 경로는 어떤 절차를 배정했는지 추적하는 데 쓴다.
3. **공유 근거**에는 이 과제에 지정한 항목의 근거 ID, 원문 링크 또는 파일과 위치, 확인 시점, 필요한 원문 발췌 또는 요약, 배경과 한계·반례를 넣는다. 발췌와 요약을 구분해 표시한다. 근거가 아직 없는 첫 리서치에는 찾아야 할 자료와 확인할 질문을 적는다. 사용이 허용된 입력만 전달하고 총괄용 기록과 다른 과제의 근거는 보내지 않는다.
4. 필요한 원문 파일은 하위가 읽을 수 있는 첨부나 공유 경로로 전달한다. 로컬 경로만 넘기는 방식은 동일 파일에 대한 하위의 접근을 확인한 경우에 사용한다. 비공개 자료는 권한이 있는 상대에게 필요한 범위만 전달한다. 필요한 맥락을 안전하게 전달할 수 없거나 원문 확인이 필수인데 하위가 원문에 접근할 수 없다면 총괄이 해당 분석을 맡거나 자료 부족으로 기록한다.

하위는 회신에 **실제로 적용한 카드 제목·경로와 절차**, **사용한 근거 ID**, **직접 연 원문과 위치**를 각각 남긴다. 메시지로 받은 발췌나 요약만 썼다면 그 범위를 표시한다. 요약을 원문처럼 인용하지 않는다. 카드나 필수 근거를 받지 못했으면 어떤 입력이 빠졌는지 먼저 반환한다. 총괄은 전달 가능한 입력을 보완해 다시 배정하거나, 원본을 읽을 수 있는 역할에서 수행한다. 임의의 다른 카드나 근거로 대체한 결과는 배정 완료로 처리하지 않는다.

## 하위가 돌려주는 결과

결과는 과제 ID와 버전, 사용한 입력과 위치, 실제 수행한 절차, 출력, 완료 기준별 충족·미충족·미확인과 근거 위치, 상태와 한계 순으로 반환한다. 수치에는 단위와 비교 조건을, 정성 패턴에는 예외를 붙인다. 모든 주장에는 다음 중 하나를 붙인다.

- **[측정/기록]** 직접 계산·측정한 값이나 기존 자료가 명시한 내용이다. 출처·시점·확인 방식을 기록한다. 인터뷰의 진술은 발언 기록으로 표시한다.
- **[추론]** 확인한 근거를 연결한 해석이다. 사용한 근거 ID와 추론 방식, 적용 범위를 적는다.
- **[추측]** 아직 확인할 자료가 필요한 가설이다. 확인에 필요한 정보와 현재 공백을 적는다.

총괄은 과제 버전, 카드, 근거 ID와 원문 확인 범위를 배정 내용 및 완료 기준과 대조한다. 취합할 때 반례와 미확인 항목의 위치를 남긴다.
