# 디자인 원칙 생성

**필수 입력:** 반복해서 확인된 요구·제약·가치 표현, 반례, 대상·매체 맥락, 근거 위치
**기대 출력:** 근거와 적용 조건·반례를 붙인 디자인 원칙 후보 여러 개와 사람의 선택 질문

**절차**

- 기록에서 반복되는 요구와 충돌하는 제약을 문장 단위로 추출하고 근거를 묶는다.
- 각 패턴을 행동 가능한 원칙 문장으로 바꾸되, 적용 대상과 조건을 함께 적는다.
- 원칙마다 지지 기록, 반례, 적용하지 않을 조건, 미확인 가정을 병기한다.
- 서로 다른 원칙 후보를 비교표로 만들고 채택·수정·반려를 사람에게 맡긴다.

완료/한계: 기록에서 도출한 원칙 후보이며 보편 규칙이나 검증된 최적 해법으로 확정하지 않는다.
