# 요약 프레임워크

**필수 입력:** 여러 카드·기록의 핵심 관찰, 대상·상황, 필요·장애, 근거 위치, 상충·공백
**기대 출력:** 맥락·대상·관찰·긴장·가능한 방향·미결정을 같은 순서로 비교할 수 있는 요약 후보

**절차**

- 모든 요약의 공통 틀을 맥락, 대상, 관찰, 필요, 긴장, 열린 질문으로 고정한다.
- 원자료의 관찰과 해석·가설을 별도 문장으로 배치하고 각 주장에 근거 위치를 붙인다.
- 서로 다른 카드의 중복은 묶되 의미가 다른 표현, 반례, 상충 결과는 보존한다.
- 길이와 강조가 다른 요약 후보를 비교해 사람에게 채택·수정·반려를 맡긴다.

완료/한계: 제공 기록을 비교 가능한 요약 후보로 정리하며 누락된 맥락이나 사람의 최종 판단을 대신하지 않는다.
