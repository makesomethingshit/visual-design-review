# 초기 기회 지도

**필수 입력:** 확인된 필요·장애·자원·제약, 관련 행위자, 가능한 변화 영역, 근거와 공백
**기대 출력:** 문제 상황에서 도출한 기회 영역 후보, 영향받는 대상, 근거·불확실성·사람의 선택 항목

## 절차

- 현재 상태 지도에서 반복되는 필요·장애와 영향을 받는 대상을 추출한다.
- 각 항목을 해결책이 아닌 변화 가능한 기회 영역 문장으로 바꾸고 관련 근거를 연결한다.
- 기회 영역을 대상·상황·제약·잠재 영향으로 비교하며 실행 가능성은 기록된 단서만 사용한다.
- 겹침·충돌·근거 부족을 표시하고 우선 탐색할 후보의 선택은 사람에게 남긴다.

완료/한계: 초기 탐색 후보의 지도이며 기회 규모·실행 가능성·우선순위를 확정하지 않는다.
