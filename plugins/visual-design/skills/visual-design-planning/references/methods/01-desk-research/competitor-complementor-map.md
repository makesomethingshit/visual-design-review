# 경쟁자·보완자 지도

**필수 입력:** 기준이 되는 제품·서비스·과제, 시장·사용 맥락, 공개·제공된 관련 사례

**기대 출력:** 경쟁자·보완자별 역할, 관계, 근거, 미확인 정보를 표시한 지도와 비교표

**절차**

1. 무엇을 경쟁 관계와 보완 관계로 볼지 과제에 맞는 판정 기준을 적는다.
2. 공개·제공 자료에서 관련 주체와 제공물을 찾아 이름·범위·출처를 기록한다.
3. 각 주체를 경쟁자, 보완자, 경계 사례로 분류하고 분류 근거를 한 줄로 남긴다.
4. 관계가 확인되지 않는 항목과 조사 범위 밖의 영역을 공백으로 표시한다.

**완료·한계:** 확인 가능한 주체와 관계를 지도에 배치하면 완료하며, 시장 전체의 완전한 목록이나 점유율 분석을 보장하지 않는다.
