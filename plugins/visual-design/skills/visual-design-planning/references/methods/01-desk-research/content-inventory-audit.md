# 콘텐츠 목록·감사

**필수 입력:** 대상 채널·페이지·파일, 목록화할 메타데이터, 제공·공개 콘텐츠

**기대 출력:** 콘텐츠 인벤토리, 중복·누락·상태 점검표, 확인이 필요한 항목

**절차**

1. 대상 범위와 항목 식별자, 제목·형식·날짜·상태 등 기록할 열을 정한다.
2. 제공 파일과 공개 채널에서 항목을 목록화하고 확인한 경로를 남긴다.
3. 항목의 목적·주제·상태를 같은 기준으로 분류하며 빈 값은 추측하지 않는다.
4. 중복, 오래된 버전, 누락, 접근 불가 항목을 각각 표시하고 우선 확인 대상을 정한다.

**완료·한계:** 정한 범위의 항목과 점검 결과를 행 단위로 추적하면 완료하며, 접근하지 못한 콘텐츠의 품질이나 최신성을 판정하지 않는다.
