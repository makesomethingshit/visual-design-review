# 즉석 조사 응답 검토

**필수 입력:** 기존 즉석 조사 응답·짧은 설문·응답 시점의 맥락, 질문 문구, 응답 ID와 수집 범위.

**기대 출력:** 상황별 즉시 반응의 주제·분포·예외, 질문 조건과 표본 한계가 표시된 요약.

**절차**

1. 질문 문구·노출 위치·응답 시점·상황을 응답과 함께 고정한다.
2. 응답자의 직접 표현과 분석자가 붙인 코드를 분리하고 누락값을 표시한다.
3. 장소·시간·상황별 응답을 비교해 반복 주제와 반례를 찾는다.
4. 수치·인용마다 응답 ID와 질문 위치를 연결하고 표본 밖 결론을 제한한다.

**자료 추적:** 결과에 질문 버전·응답 ID·수집 시점/위치와 원문을 연결한다.

**누락·편향 메모:** 접근하기 쉬운 사람과 짧은 시간에 답한 사람만 포함될 수 있다. 무응답·중도 이탈을 무관심으로 해석하지 않으며 즉시 반응을 숙고한 의견으로 일반화하지 않는다.
