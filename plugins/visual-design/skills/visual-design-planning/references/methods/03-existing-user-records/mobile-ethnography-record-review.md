# 모바일 민속지 기록 조사

**필수 입력:** 기존 모바일 일지·사진·위치·시간 기록, 앱/기기 맥락, 엔트리 식별자와 기록 기간.

**기대 출력:** 이동·시간·상황에 따른 경험 변화, 반복 행동과 전환 지점의 근거 연결 요약.

**절차**

1. 엔트리별 시간·위치·활동·매체를 정렬하고 누락된 기간을 표시한다.
2. 기록자의 서술, 이미지, 자동 위치/시간 정보가 가리키는 내용을 분리한다.
3. 장소·시간대·활동 전환에 따른 반복·우회·중단 패턴을 사례별로 비교한다.
4. 패턴과 반례를 엔트리 ID·타임스탬프에 연결하고 기록 밖 상황을 미상으로 둔다.

**자료 추적:** 각 결과에 엔트리 ID·파일명·타임스탬프·위치 기록 범위를 연결한다.

**누락·편향 메모:** 휴대기기를 사용하기 쉬운 순간과 자발적으로 기록한 경험이 과대표집된다. 오프라인·기록 누락 구간을 경험 부재로 해석하지 않는다.
