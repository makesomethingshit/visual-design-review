# 비참여 관찰 기록 조사

**필수 입력:** 기존 비참여 관찰 로그·영상·사진, 관찰 위치·시간, 관찰 단위와 기록 규칙.

**기대 출력:** 개입 없이 기록된 행동 빈도·순서·상황 패턴, 관찰 한계와 공백.

**절차**

1. 관찰자가 개입하지 않은 기록 범위와 카메라·시야·기록 간격을 정리한다.
2. 보이는 행동, 주변 조건, 해석을 분리하고 행동 단위를 동일한 기준으로 코딩한다.
3. 시간·장소·사례별 반복과 예외를 비교하되 보이지 않은 사건은 미상으로 둔다.
4. 패턴마다 원영상 타임코드·로그 행·사진 ID를 연결하고 대안 해석을 기록한다.

**자료 추적:** 관찰 세션·장비/시야 메타데이터와 원기록 위치를 각 결과에 연결한다.

**누락·편향 메모:** 카메라 위치, 관찰 가능 시간, 기록 규칙이 표본을 제한한다. 화면 밖 행동과 미기록 시간을 행동 부재로 해석하지 않는다.
