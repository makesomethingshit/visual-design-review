# 기존 설문 응답 조사

**필수 입력:** 기존 설문 응답 데이터, 질문지 버전·코드북, 표본·응답 수, 수집 기간과 분석 질문.

**기대 출력:** 문항별 응답 분포·조건부 차이·서술 응답 주제, 결측·무응답과 표본 한계.

**절차**

1. 질문 문구·응답 척도·버전과 표본·응답·무응답 수를 먼저 고정한다.
2. 코드북에 따라 결측·복수응답·자유응답을 분리하고 임의의 의미를 부여하지 않는다.
3. 사전에 정한 세그먼트와 기간으로 분포·차이·서술 주제를 비교한다.
4. 수치와 인용을 문항 ID·응답 레코드/추출본에 연결하고 가능한 결론의 범위를 기록한다.

**자료 추적:** 결과에 설문 버전·문항 ID·추출 파일·응답 범위와 분석 조건을 연결한다.

**누락·편향 메모:** 응답·무응답, 질문 문구, 응답 척도와 표본 프레임이 결과를 치우칠 수 있다. 응답자의 자기보고를 실제 행동으로 바꾸지 않고 결측을 0으로 처리하지 않는다.
