# 포커스 그룹 기록 조사

**필수 입력:** 기존 포커스 그룹 녹취·영상·요약, 발화자 표기, 그룹 구성 정보, 진행자 질문지.

**기대 출력:** 집단 내 합의·이견·상호작용 패턴과 발화 근거, 그룹 간 차이와 공백.

**절차**

1. 발화 순서와 발화자를 보존한 채 질문·응답·동의·반박·침묵을 표시한다.
2. 개인 진술, 다른 사람의 영향으로 형성된 합의, 소수 의견을 분리한다.
3. 그룹별 주제·이견·전환 지점을 비교하고 대표 발화와 반례를 함께 뽑는다.
4. 주제별 해석을 발화자·그룹·타임코드에 연결하고 말하지 않은 항목을 공백으로 기록한다.

**자료 추적:** 결과에 그룹 ID·발화자 표기·녹취 타임코드를 연결한다.

**누락·편향 메모:** 발언이 큰 사람, 진행자 프레이밍, 집단 동조가 응답을 과대표집할 수 있다. 침묵을 동의로 해석하지 않으며 소수 그룹을 전체 사용자로 일반화하지 않는다.
