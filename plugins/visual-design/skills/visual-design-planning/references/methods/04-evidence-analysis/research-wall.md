# 리서치 월

**필수 입력:** 기존 조사 자료·관찰·인용 카드, 자료 ID·출처·시점·원문 위치, 과제 질문

**기대 출력:** 질문·주제·자료 유형별 정렬 보드와 근거 공백·충돌·후속 확인 목록

**절차**

1. 각 자료를 한 사실·관찰·질문 단위 카드로 만들고 출처, 위치, 시점, 대상, 상태를 적는다.
2. 카드를 질문·주제·자료 유형 또는 시간순으로 배치해 같은 근거와 다른 근거가 보이게 한다.
3. 중복·충돌·근거가 없는 카드를 연결하고, 연결 이유를 원문 범위와 함께 적는다.
4. 보드에서 과제 질문에 답하는 카드 묶음, 공백, 확인 불가 항목을 `claim/evidence/status` 목록으로 추출한다.

**완료·한계:** 모든 입력 카드와 배치 기준을 보존한다; 보드는 자료의 구조를 보여주는 기록이며 새 조사를 수행하거나 시각적 근접성을 상관관계로 해석하지 않고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
