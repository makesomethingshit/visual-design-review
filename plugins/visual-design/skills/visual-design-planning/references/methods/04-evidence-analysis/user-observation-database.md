# 사용자 관찰 데이터베이스

**필수 입력:** 기존 사용자 관찰 기록, 관찰 단위·대상·상황·시점·출처, 과제에서 조회할 필드

**기대 출력:** 원문으로 되돌아갈 수 있는 관찰 레코드 집합과 필드별 상태·코드·한계

## 절차

1. 관찰마다 고유 ID를 부여하고 원문 위치, 기록 시점, 대상, 상황, 관찰 사실을 별도 필드로 입력한다.
2. 해석·코드·관련 과제·근거 링크를 관찰 사실과 분리해 연결하고, 비어 있는 값은 미상·해당 없음으로 구분한다.
3. 중복 기록은 원본 ID를 보존한 채 연결하고, 충돌·수정 이력·출처가 없는 요약을 별도 상태로 표시한다.
4. 표본 레코드를 원문과 대조한 뒤 필요한 질의가 재현되도록 필드 정의·필터·결과 행을 기록한다.

**완료·한계:** 입력 관찰의 보존·추적·누락 상태를 점검한다; 데이터베이스 구축은 기록 정리이며 개인정보 보강, 새 관찰 수집, 모집단 대표성 검증을 포함하지 않고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
