# 내용 분석

**필수 입력:** 분석할 문서·발화·시각 자료의 텍스트, 분석 단위·코드 규칙, 출처·위치·시점

**기대 출력:** 코드별 내용 패턴, 빈도 또는 존재 여부, 대표 원문·예외·해석 범위

**절차**

1. 문서·발화·캡션 등 분석 단위를 정하고 각 단위에 원문 위치와 자료 메타데이터를 붙인다.
2. 과제 질문에서 확인할 개념·행동·주장 코드를 정의하고, 한 단위에 여러 코드가 붙는 조건을 적는다.
3. 모든 단위에 코드를 적용해 존재·부재·판정 불가를 구분하고, 계산한 횟수는 분석 단위 수로 한정한다.
4. 코드별 대표 원문과 반례를 원자료와 대조한 뒤 `기록/추론/추측`을 나누어 결과를 회신한다.

**완료·한계:** 적용 대상·코드·미분류 단위를 모두 공개한다; 코드 빈도는 언급량일 뿐 의미의 중요도·진실·전체 집단 비율을 증명하지 않으며 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
