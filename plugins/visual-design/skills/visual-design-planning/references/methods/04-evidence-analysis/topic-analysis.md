# 주제 분석

**필수 입력:** 과제 질문, 분석 대상 텍스트·기존 기록, 자료 ID·원문 위치·시점

**기대 출력:** 주제 코드 목록과 주장별 근거 ID·원문 위치·관찰/추론/추측 구분

**절차**

1. 자료를 문장·발화·기록 단위로 나누고 각 단위에 자료 ID와 원문 위치를 붙인다.
2. 과제 질문에 직접 관련된 반복 의미를 짧은 중립 코드로 표시하고, 서로 다른 표현의 같은 의미는 연결한다.
3. 코드를 상위 주제로 묶되 빈도만으로 중요도를 정하지 않고 대표 근거와 반대·예외 근거를 함께 기록한다.
4. 각 주제에 `주장 ID → 근거 ID → 위치/시점` 행을 만들고 관찰된 내용과 해석을 분리한다.

**완료·한계:** 모든 분석 단위의 포함·제외 상태와 미분류를 남긴다; 기존 자료 분석만 하며 새 인터뷰나 주제의 학술적 타당성을 검증하지 않고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
