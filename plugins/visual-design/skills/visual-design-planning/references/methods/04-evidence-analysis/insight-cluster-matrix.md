# 통찰 군집 매트릭스

**필수 입력:** 통찰 목록, 통찰별 근거·대상·상황·상태, 비교할 행·열 차원과 과제 질문

**기대 출력:** 통찰 간 교차 매트릭스, 군집·공백·충돌과 셀별 근거 ID

**절차**

1. 중복 없는 통찰을 행에, 과제에 필요한 비교 차원을 열에 두고 각 차원의 정의를 고정한다.
2. 통찰을 해당 셀에 배치하고 근거 ID·대상·시점을 함께 기록하며 자료에 없는 셀은 빈칸으로 둔다.
3. 인접 통찰을 군집으로 묶고, 같은 군집 안의 공통점과 군집 사이의 차이를 원문 근거로 설명한다.
4. 행·열을 바꿔도 결론이 달라지는 지점, 상충 셀, 미확인 셀을 점검해 `통찰 → 셀 → 근거`로 제출한다.

**완료·한계:** 모든 통찰과 셀의 미확인·해당 없음 상태를 구분한다; 매트릭스의 빈도나 밀집이 중요도·인과·대표성을 뜻하지 않으며 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
