# 대칭 군집 매트릭스

**필수 입력:** 비교할 항목 목록, 동일한 행·열 집합, 항목 간 관계 기준, 항목 ID·근거 위치

**기대 출력:** 대칭 관계 매트릭스, 쌍별 근거·군집·고립 항목·관계 미확인 목록

**절차**

1. 동일한 항목 집합을 행과 열에 같은 순서로 배치하고 대각선·중복 셀의 의미를 정의한다.
2. 두 항목의 관계를 유사·공통·차이·관계 없음·판정 불가 중 과제에 필요한 상태로 기록한다.
3. 상호 관계가 같은지 `(A,B)`와 `(B,A)`를 대조하고 비대칭으로 보이는 기록은 근거와 함께 보류한다.
4. 반복되는 관계를 군집으로 묶고 각 셀을 항목 ID·근거 ID·원문 위치로 추적해 고립·충돌을 보고한다.

**완료·한계:** 모든 쌍과 대각선·미확인 셀의 상태를 채운다; 행·열 대칭은 분석 형식일 뿐 실제 관계의 동등성·유사성 원인·중요도를 증명하지 않으며 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
