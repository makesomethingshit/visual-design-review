# 기존 관찰 기록 분류틀

**필수 입력:** 기존 관찰 기록·메모·이미지 설명, 분류 차원과 코드 정의, 기록 ID·관찰 위치·시점

**기대 출력:** 관찰 단위별 코드·원문·맥락·예외·미분류 사유의 일관된 분류표

## 절차

1. 관찰 사실과 관찰자의 해석·평가를 나누고, 각각의 원문 범위와 기록 맥락을 표시한다.
2. 과제에 필요한 행동·환경·도구·사람·상호작용 등 코드 정의를 먼저 적고 포함·제외 예시를 고정한다.
3. 모든 관찰 단위에 코드를 적용하되 여러 코드, 코드 간 충돌, 코드 없음 상태를 허용한다.
4. 코드별 대표·반대·불명확 사례를 다시 원문과 대조하고 `기록 ID → 코드 → 원문 위치`로 제출하며 분류자 판단이 들어간 부분을 `추론`으로 표시한다.

**완료·한계:** 기록 단위 전체가 코드·미분류·제외 중 하나로 닫힌다; 기존 기록의 분류틀이며 관찰 당시 상황을 재현하거나 새로운 관찰의 신뢰도를 검증하지 않고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
