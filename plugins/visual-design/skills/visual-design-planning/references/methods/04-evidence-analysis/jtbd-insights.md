# JTBD 통찰

**필수 입력:** 기존 사용자 발화·관찰·행동 기록, 상황·목표·장애 단서, 자료 ID·원문 위치·시점

**기대 출력:** 상황-동기-기대 결과-장애 구조와 각 요소의 근거·불확실성·예외

**절차**

1. 기록에서 사용자가 처한 상황과 시작 계기, 하려는 일을 원문에 가깝게 추출한다.
2. 기능 요청과 그 뒤의 기대 결과·불안·제약을 분리하고, 기록에 없는 동기는 추측으로 표시한다.
3. 각 작업 문장을 `상황에서 원하는 진전` 형식의 후보로 정리하고 서로 다른 상황을 합치지 않는다.
4. 후보별 근거 ID, 반대 사례, 아직 확인할 질문을 연결해 과제 질문과 직접 관련된 것만 통찰로 회신한다.

**완료·한계:** 기록에 없는 목적을 보충하지 않고 미확인 상태를 보존한다; 기존 자료를 JTBD 관점으로 재구성할 뿐 실제 작업 우선순위나 대표성을 검증하지 않으며 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
