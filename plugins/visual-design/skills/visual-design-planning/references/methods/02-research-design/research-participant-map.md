# 조사 참여자 지도

**필수 입력:** 조사 질문, 대상 사용자·이해관계자 범위, 필요한 경험·역할 정보, 접근 제약

**기대 출력:** 참여자·이해관계자 유형, 포함 이유, 필요한 질문, 접근 상태를 정리한 지도

**절차**

1. 조사 질문에 필요한 경험·역할·의사결정 위치를 참여자 유형으로 나눈다.
2. 유형마다 알고 싶은 정보와 제외하면 생기는 공백을 연결한다.
3. 제공된 기록과 공개 자료로 확인 가능한 유형과 사람의 후속 접촉이 필요한 유형을 표시한다.
4. 모집·동의·접근 조건은 실행 전제와 미결정 항목으로 남기고 참여자를 만들어내지 않는다.

**완료·한계:** 유형과 정보 필요성이 지도에 연결되면 완료하며, 실제 모집·대표성·응답 결과를 제공하지 않는 조사 설계 산출물이다.
