# 멘탈 모델 다이어그램

**필수 입력:** 기록에 명시된 기대, 개념, 용어, 규칙 이해, 사용자가 예상한 결과, 혼동 단서
**기대 출력:** 대상의 개념 구조와 기대-실제 차이, 근거, 가설을 구분한 멘탈 모델 다이어그램

**절차**

- 대상이 사용한 용어와 개념을 원문 그대로 추출하고 서로의 상하·연결 관계를 배치한다.
- 각 개념에 기대 행동·예상 결과·필요한 설명을 연결하고 발언 또는 기록 위치를 붙인다.
- 제공된 시스템 설명이나 결과와 어긋나는 지점을 사실 차이와 해석 가설로 나눈다.
- 용어가 다르게 쓰인 기록, 남은 혼동, 사람에게 확인할 질문을 별도 표시한다.

완료/한계: 기록된 기대와 개념의 비교도이며 실제 인지 구조나 원인을 측정·확정하지 않는다.
