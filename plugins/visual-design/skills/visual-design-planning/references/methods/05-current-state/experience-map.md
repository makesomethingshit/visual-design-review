# 경험 지도

**필수 입력:** 여러 기록에서 확인 가능한 대상 집단, 공통 단계, 행동·생각·감정 표현, 상황 단서
**기대 출력:** 집단의 공통 경험 패턴과 단계별 차이·근거·미확인 항목을 비교하는 경험 지도

## 절차

- 대상 집단과 경험의 시작·종료 범위를 기록에 맞춰 정하고 대표 표현을 그대로 모은다.
- 단계 또는 상황별로 행동, 생각, 감정, 필요를 별도 행에 배치한다.
- 여러 대상의 반복·차이·전환을 묶되, 기록되지 않은 공통성은 추론이나 추측으로 표시한다.
- 경험을 바꾸는 조건과 추가 확인이 필요한 빈칸을 근거 위치와 함께 남긴다.

완료/한계: 기록에 드러난 경험 패턴의 비교안이며 집단 전체나 실제 감정을 대표한다고 주장하지 않는다.
