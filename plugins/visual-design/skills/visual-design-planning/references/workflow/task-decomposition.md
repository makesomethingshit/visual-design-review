# 과제 분할

1. 합의한 결과물의 필수 항목을 질문으로 바꾼다. “경쟁 가격 알아보기” 대신 “같은 판매 채널에서 100mL당 실판매가는 얼마인가?”처럼 대상·기준·범위를 포함한다.
2. 질문마다 필요한 자료, 요구 출력의 항목·단위·대상·비교 범위, 완료 기준을 적는다. 완료 기준은 제출물과 대조할 수 있게 쓴다. 예를 들어 상품별 표시가·용량·판매처·확인일과 100mL당 환산식이 있어야 한다.
3. 어떤 과제의 결과가 다른 과제에 반드시 필요한지 표시한다. 예를 들어 상품 동등성 기준을 정한 후 가격을 비교한다. 출력과 근거를 독립적으로 검증할 수 있으면 분리하고, 같은 자료를 같은 기준으로 반복 읽는 작업은 묶는다.
4. 과제 ID와 버전을 부여한 후 방법론 인덱스에서 해당 출력을 낼 방법을 찾는다. 질문이나 완료 기준이 바뀌면 이유와 버전을 남기고 영향받는 과제만 재배정한다.
