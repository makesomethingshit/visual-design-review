# 근거 매핑 계약 (`30-evidence-map.md`)

시안의 값이 레벨 1의 어느 근거에서 나왔는지, 어디서 벗어났는지, 아직 확인되지 않은 것이 무엇인지 한 표로 남기는 형식이다. 이 표가 없으면 레벨 3은 값의 출처를 알 수 없고, 레벨 2는 나중에 자기 선택을 근거에 끼워 맞추게 된다.

## 항목 ID

- 조형 판단 단위로 `E-<영역>-<번호>`를 붙인다: `E-GRID-01`, `E-TYPE-03`, `E-COLOR-02`, `E-ASSET-01`, `E-REF-01`.
- 같은 항목을 여러 시안이 같은 값으로 쓰면 한 행에 `A, B`로 적는다. 값이 다르면 시안별로 행을 나눈다.
- 번호는 다시 쓰지 않는다. 항목을 지우면 행을 지우지 않고 `상태`에 `RETIRED`와 이유를 남긴다.

## 표의 열

| 열 | 내용 |
| --- | --- |
| 항목 ID | 위 규칙의 ID |
| 시안 | `A` / `B` / `C`, 같은 값이면 `A, B` |
| 조형 요소 | 무엇인지 + 시안에서 찾을 위치(선택자·레이어 이름·캡처 영역). 예: `index.html .time-band` |
| 값·단위 | 정한 값과 단위. 여러 값이면 한 행에 묶지 않는다 |
| 레벨 1 근거 ID | `evidence-index.md`의 ID 그대로. 없으면 `NO-EVIDENCE`, 리뷰 문장만 있으면 `ALIAS-01` |
| 번역 ID | `20-translation.md`의 `T` ID. 번역을 거치지 않은 값은 `-` |
| 관계 | `FOLLOWS` / `DEVIATES` / `NEW` / `CONFLICT` |
| 상태 | `decision status` / `verification` (아래 어휘) |
| 비고 | 벗어난 이유, 잃는 것, 확인할 조건 등 |

## 관계 어휘

| 관계 | 뜻 | 함께 적어야 하는 것 |
| --- | --- | --- |
| `FOLLOWS` | 근거가 이 값을 직접 지지 | 근거 위치(주장·표·행) 또는 번역 ID |
| `DEVIATES` | 근거와 다르게 정함 | 어긋난 근거 ID, 이유, 잃는 것·얻는 것, 사람 승인 여부 |
| `NEW` | 근거가 없어 새로 정함 | 값의 출처(가정·후보·도구 기본값), 가정이 바뀌면 달라지는 것 |
| `CONFLICT` | 근거끼리 또는 제약끼리 충돌 | 충돌한 ID 둘 이상, 어느 쪽을 택했는지, 결정 주체 |

`DEVIATES`와 `NEW`는 시안을 만들지 말라는 뜻이 아니다. 값의 출처를 숨기지 말라는 뜻이다. 사람의 승인 없이 `DETERMINED`로 올리지만 않으면 된다.

## 상태 어휘

`design-handoff` 계약과 같은 어휘를 쓴다. 두 축을 붙여 `DETERMINED / FORMULA_CHECKED`처럼 적는다.

| 축 | 값 |
| --- | --- |
| decision status | `DETERMINED` / `PROJECT_INITIAL_PRESET` / `CANDIDATE` / `UNRESOLVED` / `CONFLICT` |
| verification | `FORMULA_CHECKED` / `SOURCE_MEASURED` / `TOOL_APPLIED` / `OUTPUT_INSPECTED` / `UNVERIFIED` |

- 계산으로 얻은 값은 `FORMULA_CHECKED`까지다. 실제 조판·렌더를 확인하지 않았으면 `UNVERIFIED`를 함께 적는다.
- 사람이 고르지 않은 값은 `CANDIDATE`다. 시안에 들어갔다는 사실로 `DETERMINED`가 되지 않는다.
- `PROJECT_INITIAL_PRESET`은 적용 근거가 확인된 정책값에만 쓴다.

## 추적 범위

행을 만드는 대상은 판단이 걸린 요소다.

| 행을 만든다 | 한 행으로 묶는다 |
| --- | --- |
| 판면·단폭·여백·기준선 격자 | 같은 스타일을 공유하는 캡션 여러 개 |
| 역할별 서체·크기·행간·자간·줄 길이 | 한 역할 안의 반복 항목 |
| 색의 역할과 값, 대비 | 장식적 구분선·아이콘 크기 |
| 이미지 크롭·비율·배치·해상도 | 반복되는 목록 항목의 개별 여백 |
| 레퍼런스에서 가져온 원리 | 도구 기본값을 그대로 쓴 속성 |

묶은 행은 무엇을 묶었는지 비고에 적는다. 모든 픽셀 값의 목록을 만들지 않는다.

## 양방향 검증

표를 닫기 전에 네 가지를 확인한다.

1. **인계 → 표:** `10-intake.md`의 모든 `EV`·`DIR`·`C`·`U` ID가 표에 나오거나, 표 말미의 "쓰지 않음" 목록에 이유와 함께 있다.
2. **표 → 인계:** 표에 적힌 레벨 1 ID가 모두 `10-intake.md`에 있다. 없으면 그 행은 `NO-EVIDENCE`이고, 인계에 없는 ID를 사후에 만들지 않는다.
3. **값의 중복 없음:** 값은 `20-translation.md` 또는 표 중 한 곳에만 있다. 두 곳이 다르면 표를 고치지 않고 번역 값을 고친 뒤 이유를 남긴다.
4. **시안과의 대면:** 표의 `조형 요소` 위치를 실제 시안 파일에서 찾을 수 있어야 한다. 찾을 수 없으면 표가 아니라 시안이 바뀐 것이므로 둘을 맞춘다.

## 시안 비교표

차이 축과 시안별 위치를 한 표로 남긴다. 우열을 점수로 매기지 않고, 무엇을 기준으로 고르게 되는지 드러낸다.

| 시안 | 차이 축에서의 위치 | 핵심 판단 | 제작 난이도 | 남은 위험 |
| --- | --- | --- | --- | --- |
| A | 시간 띠를 상단 전폭으로 | 시간 인지 최우선 | 낮음 | 띠가 커지면 하단 정보 압축 |
| B | 시간 숫자를 키우고 띠를 없앰 | 이미지와 시간의 동시 노출 | 중간 | 작은 화면에서 숫자 잘림 |

"제작 난이도"에는 근거가 있으면 출처를 적는다. 추정이면 추정이라고 적는다.

## 예시 (합성)

같은 실행의 리플릿 1면을 가정한 형식 예시다. 실제 작품의 값이 아니다.

| 항목 ID | 시안 | 조형 요소 | 값·단위 | 레벨 1 근거 ID | 번역 ID | 관계 | 상태 | 비고 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| E-GRID-01 | A, B | `index.html .col` 본 단폭 | 38 mm | EV-04 | T-01 | FOLLOWS | DETERMINED / FORMULA_CHECKED | DG-1, 판형 고정값 |
| E-GRID-02 | A | `index.html .time-band` 높이 | 46 mm | EV-07 | T-02 | NEW | CANDIDATE / UNVERIFIED | 근거 없음, A만 |
| E-TYPE-01 | A | `.time-num` 크기 | 44 pt | EV-07 | T-05 | FOLLOWS | PROJECT_INITIAL_PRESET / UNVERIFIED | 첫 비교 시안값 |
| E-TYPE-01 | B | `.time-num` 크기 | 32 pt | EV-07 | T-06 | DEVIATES | CANDIDATE / UNVERIFIED | 이미지와 균형을 위해 낮춤. 잃는 것: 3초 인지 |
| E-COLOR-01 | A, B | 바탕·문자 역할 | 2색 | C-02 | T-09 | NEW | UNRESOLVED | 후보 팔레트 2개, 사람 선택 전 |

`E-TYPE-01`처럼 같은 항목에 시안별 값이 다르면 행을 나누고, `E-GRID-01`처럼 값이 같으면 한 행에 시안을 함께 적는다.

## 이 표에서 하지 않는 일

- 없는 근거 ID·원문 위치·파일 경로를 만들지 않는다.
- 사람이 고르지 않은 값을 `DETERMINED`로 올리지 않는다.
- 시안의 미적 우열을 점수나 순위로 만들지 않는다. 차이는 값·근거·영향으로 적고 선택은 사람이 한다.
- 레벨 3의 심각도 판정을 미리 붙이지 않는다. 발견 사항은 레벨 3의 일이다.
