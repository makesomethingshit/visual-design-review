# 레벨 2 실행 흐름 (초안)

레벨 2는 레벨 1의 판단을 실제 조형으로 옮기고, 사람이 비교할 수 있는 시안을 만든다. 아래 순서는 고정된 한 번의 통과가 아니라, 결정이 바뀌면 이전 단계로 돌아가는 흐름이다. 이 문서는 뼈대이며, 각 단계의 세부 규칙은 실제 작업 사례가 쌓이면 보강한다.

## 1. 인계 자산 로드

1. 레벨 1 실행 폴더에서 `review-v1.md` 또는 사람이 채택한 다음 버전을 찾아 연다. 없으면 사람에게 위치를 확인한다.
2. 다음 네 가지를 실행 폴더의 작업 기록으로 옮겨 적는다. 근거 ID는 원문 위치와 함께 남긴다.
   - 채택된 방향과 그 근거 ID
   - 제작 제약(판형·매체·원고·자산·일정 등)
   - 미결 쟁점과 그 결정 주체
   - 레벨 1에서 남긴 공백·한계(있으면 시안의 가정으로 표시)
3. 인계 자산이 없거나 부분적이면 최소 맥락만 확인하고 시작한다. 목적·대상·매체·콘텐츠·제약 중 시안 구조를 바꾸는 것만 묻고, 확인된 것과 가정한 것을 구분해 기록한다. 레벨 1을 대신 수행하지 않는다.

## 2. 조형 번역

기획 근거를 조형 변수로 옮긴다. 각 변환은 근거 ID와 연결하고, 근거 없이 정한 값은 가정으로 표시한다.

| 조형 영역 | 옮길 내용 | 근거가 없을 때 |
| --- | --- | --- |
| 레이아웃·그리드 | 정보 위계, 판면, 단·여백, 요소 간 관계 | 후보와 판단 기준을 제시하고 미결로 둔다 |
| 서체 페어링·타이포 위계 | 역할별 서체·크기·행간·자간·줄 길이의 관계 | 측정·확인이 필요한 값은 미검증으로 둔다 |
| 컬러·톤 | 목적·대상·매체에서 나온 색 역할과 대비 | 승인 없이 팔레트를 확정하지 않는다 |
| 레퍼런스 생성 규칙 | 참조 작품의 구조·관계 가설 | `visual-design-review` 스킬의 `references/reference-analysis.md` 절차를 따르고, 보이는 결과와 원저자 의도를 구분한다 |

수치가 필요한 판단은 계산 근거를 함께 남긴다. 근거 없는 황금비·배율·보정값을 채우지 않는다.

## 3. 복수 시안 생성

1. 방향 차이가 비교 가능하도록 시안을 둘 이상(A/B 등) 만든다. 같은 방향의 미세 변형만 늘리지 않는다.
2. 실제 산출물로 만든다. 사용할 수 있는 도구가 있으면 그 도구로(예: SVG·HTML 파일, 연결된 디자인 도구), 없으면 만들 수 있는 형식으로 만든다. 만들지 못했으면 이유와 필요한 도구를 밝힌다.
3. 시안마다 다음을 기록한다.
   - 시안 ID와 파일 경로
   - 어떤 레벨 1 근거 ID를 따랐는지
   - 근거에서 벗어난 결정과 그 이유
   - 아직 확인되지 않은 값
4. 시안 비교표에 차이 축(위계·밀도·톤·제작 난이도 등)을 적어, 사람이 무엇을 기준으로 고르는지 알 수 있게 한다.

## 4. 선택·확정 및 인계

1. 사람이 시안을 고르거나 보완을 지시한다. 채택 전에는 확정으로 부르지 않는다.
2. 채택된 시안은 확정 시안으로 정리하고, 제작에 필요한 값을 설계 스펙으로 남긴다. 스펙 형식은 `visual-design-review` 스킬의 `references/design-handoff.md` 계약을 따른다.
3. 레벨 3(`visual-design-review`) 검수로 넘긴다. 인계 시 다음을 함께 전달한다.
   - 확정 시안과 산출물 경로
   - 설계 스펙과 값의 출처·검증 상태
   - 미결·가정·미검증 항목
   - 레벨 1 근거 ID와의 연결
4. 검수에서 지적이 오면 영향받은 시안과 스펙만 다시 열고, 목표나 범위가 바뀌면 레벨 1 맥락부터 확인한다.

레벨 2는 조형 결정과 시안 제작까지다. 완성 작품의 비평·심각도 판정·출력 프리플라이트는 레벨 3이 맡는다.
