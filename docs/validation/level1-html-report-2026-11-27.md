> 대상 모델(Codex)이 아니라 Claude(claude-opus-5-5) 하위 에이전트로 실행했다. 실행 에이전트에게는 기준 샘플을 보여 주지 않았다. 판정은 두 보고서의 출처를 가리고(A/B, 회차마다 순서를 바꿈) 별도 에이전트가 분석의 질 7개 기준으로 1~5점을 매겼으며, 각 보고서의 수치 일부를 원문과 대조했다. 같은 모델 계열이 쓰고 판정했으므로 사람 평가를 대신하지 않는다. 회차마다 한 번씩 실행했다.

- 기준 샘플: 사용자가 준 같은 주제의 보고서(다른 실행의 결과물)
- 웹 검색·열람 허용. 일부 학술 DB 원문은 접근 차단이나 열람 승인 미응답으로 열지 못했다(각 실행의 한계 절).

같은 샘플인데 두 판정에서 점수가 다르다(28, 24). 판정자가 다르고 비교 상대가 달랐기 때문이며, 점수는 회차 안의 상대 비교로만 읽는다. 원본 판정: [`blind-run1-vs-sample.json`](level1-html-report-2026-11-27/blind-run1-vs-sample.json), [`blind-run2-vs-sample.json`](level1-html-report-2026-11-27/blind-run2-vs-sample.json).

- **run1**: 구조는 샘플보다 촘촘했지만 근거 대부분이 기사 재인용·초록·전 연령 자료였고, 여정의 단계 구조를 관찰이 아니라 지침에서 만들었으며, 분모가 다른 비율을 맞비교했다. 형식만으로는 분석 수준이 올라가지 않았다.
- **run2**: 분석 기준을 넣은 뒤 대상 집단을 직접 관찰한 1차 연구 3편과 원자료로 단계별 성공률을 짚고, 같은 응답자·같은 문항 안에서만 전제를 비교했다. 원문 대조 7건 중 run2의 3건은 일치했고, 하나는 조건 기술이 다소 느슨했다.

## run2에 남은 약점과 처리

| 약점 | 처리 |
| --- | --- |
| 샘플이 쓴 '처음 쓰는' 사용자 관찰 연구를 찾지 못하고 그런 연구가 없다고 씀 | 분석 기준에 브리프 대상 조건에 맞는 근거를 먼저 찾고, 없다고 쓰기 전에 다시 찾는 규칙 |
| 단계별 성공률 차이만으로 글씨를 원인에서 배제 | 원인 배제 전 교란 요인 확인 규칙 |
| 출처 간 충돌(결제 성공 90% 대 8명 전원 결제 진행 모름)을 풀지 않음 | 출처끼리 결과가 다르면 설명하거나 남은 쟁점에 올리는 규칙 |
| 원칙·HMW에 근거 무게 순서가 없음 | 근거 무게로 순서를 매기고, 반대 근거와 견주는 규칙 |

이 마지막 보완은 다시 실행해 확인하지 않았다.
