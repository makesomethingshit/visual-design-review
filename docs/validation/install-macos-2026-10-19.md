# macOS 설치·업데이트 검증

2026-10-19 JST, PR #3의 원본 HEAD `cb3207ba93f375c081c06953bcf22cdeeb2f0355`를 기준으로 검증했다. 환경은 macOS 15.7.5 / arm64, 기본 `/bin/bash` 3.2.57, Codex CLI 0.163.0이다.

## 원본과 수정본 구분

원본 `scripts/install-linux.sh`의 Git blob SHA는 `1cdfee9c5a478dd23533b8abf2e84e4ded9a9390`으로 PR과 일치했다. 원본의 install/check/remove에 dry-run을 지정하면 모두 운영체제 검사에서 종료 코드 2로 중단됐다. 임시 CODEX_HOME은 생성되지 않았다. 따라서 원본 PR이 macOS 설치 시험에 통과했다고 해석하면 안 된다.

수정본은 Darwin을 허용하고, sha256sum이 없을 때 shasum -a 256을 사용한다. 그 외 설치·백업·복원 로직과 스킬 본문은 유지했다. 설치와 모든 시험은 별도의 임시 CODEX_HOME에서 수행했다.

## 실제 실행 결과

Codex app-server를 각 단계마다 새로 시작해 initialize/initialized 후 skills/list(forceReload=true)를 호출했다. 별도 빈 작업 폴더에서 대상 이름은 설치 후 1개, 업데이트 후 1개, 제거 후 0개, 수동 복구 후 1개로 검색됐다. 설치된 항목의 경로가 시험용 CODEX_HOME 안에 있는지도 확인했다. 백업이 중복 스킬로 발견되지 않았다. 인증 파일 복사나 모델 요청은 수행하지 않았다.

처음 검색 시험에서는 macOS의 `/var`와 `/private/var` 별칭 경로를 문자열로 비교해 검증 코드가 실패했다. 실제 검색 결과는 이미 1개였다. 경로를 resolve한 뒤 전체 시험을 다시 실행해 통과했으며, 첫 실패를 제품 결함으로 기록하지 않았다.

파일 시스템 회귀는 `/bin/bash tests/smoke-install-macos.sh`로 재현한다. 이 명령에는 일반·shasum 대체 경로, 한글·공백 경로, 강제 활성화 실패/복원 시험이 포함된다. Codex app-server 검색 결과는 별도 로컬 실행 기록이며 CI 시험에는 포함하지 않았다.

## 범위와 한계

- 성공 기록은 호환성 수정본에 해당하며 원본 PR에 소급하지 않는다.
- 로컬 macOS 단일 버전·arm64 결과다. Intel Mac, 다른 OS 버전, 권한 거부·디스크 부족의 모든 조합은 미검증이다.
- 스킬 검색은 확인했지만 새 모델 세션의 자연어 라우팅 및 이미지 비평 품질은 이번 시험 범위 밖이다.
- 원격 버전 자동 다운로드·주기적 업데이트는 구현하거나 시험하지 않았다.
- Windows·Ubuntu는 이 변경 후 로컬에서 재실행하지 않았다. 새 CI 결과는 해당 커밋의 Actions 결과로 따로 확인해야 한다.
- 개인 경로·호스트명·인증 정보가 포함될 수 있는 원문 로그는 업로드하지 않았다.
