PROBLEM STATEMENT점심시간 줄 앞에서 키오스크를 처음 쓰는 60대 이상 손님은 글씨를 못 읽어서라기보다, 주문 도중 끼어드는 선택·팝업과 예측하기 어려운 화면 전환을 뒤에서 기다리는 사람을 의식하며 처리해야 하고, 잘못 눌렀을 때 혼자 되돌아갈 길이 보이지 않아 직원을 부르거나 포기한다.

공개 근거로 보면 "글씨가 작다"는 실제로 있는 막힘이지만 혼자 주문을 끝내지 못하는 이유의 일부일 뿐이고, 같은 조사들에서 '조작·작동 방법의 복잡함'과 '뒷사람 눈치(시간 압박)'가 글씨와 같거나 더 높게 보고됩니다 [추론]3478. 따라서 개편은 화면 키우기가 아니라 주문 흐름(한 화면 한 결정, 기본값, 시간제한 없음, 고정된 되돌리기·도움 버튼)을 먼저 다루고 가독성 최소 기준을 함께 지키는 쪽으로 정의하는 것이 근거와 맞습니다. 단, 자사 화면·이용 기록·매장 보고 원문이 없어 우리 매장에서 실제로 어느 단계에서 막히는지는 모릅니다. 수치 대부분은 패스트푸드·전 업종 자료이고 기사 재인용이 많아, 분식 메뉴(맵기·사리·추가 토핑 등)의 부담은 확인되지 않았습니다.

문제 들여다보기

문헌·기존자료 조사

불편 이유를 물은 세 조사 모두에서 '조작·작동'이나 '눈치'가 '글씨'와 같거나 더 높게 나왔다

본부 가설("글씨가 작아서")을 공개 조사의 응답 이유와 나란히 놓기 위해 골랐습니다. 세 조사는 문항·대상·시점이 달라 막대끼리 직접 비교하지 않고, 조사 안에서의 순서만 읽습니다. 한국소비자원 두 건은 원 보도자료를 열지 못한 기사 재인용이고, 롯데멤버스 자료의 이유 항목은 전 연령 합계입니다.

이 그림이 말하는 것 가독성은 실제로 꼽히는 이유지만(A 44.1%, B 20%+), 같은 조사 안에서 조작·작동의 어려움(A 51.4%, B 53%)과 뒷사람 눈치(A 49%, C 44.9%)가 같거나 더 높습니다 [측정/기록]347. 글씨만 키우면 나머지 두 축은 그대로 남는다고 읽습니다 [추론].

과업 분석

주문 한 건은 8단계·최소 6개 결정이며, 기록된 막힘은 '결정이 끼어드는 단계'에 몰려 있다

본부 목표가 '혼자 끝내기'라서 주문 흐름을 단계별로 쪼개 어디서 막히는지 보려고 골랐습니다. 자사 화면이 없어 단계 구조는 공개 지침과 패스트푸드형 키오스크 자료에서 일반화한 것이며, 우리 화면의 실제 단계·팝업 수와 분식 옵션 구조는 확인하지 못했습니다(T8 대기).

단계하위 행동·결정기록된 장애 단서상태
1. 시작키오스크 앞에 서서 시작 화면 이해미이용 이유 1위 "사용방법을 모르거나 어려워서" 33.8%(55세 이상 미이용자)1[측정/기록]
2. 매장/포장결정 ① 먹고 갈지·가져갈지공개 기록 없음미확인
3. 메뉴 찾기결정 ② 분류 선택 → 메뉴 선택메뉴 찾기 어려움 28.6%(전 연령)7; 분류가 한 줄을 넘어 옆으로 넘기면 탐색 못 함11; 화면 배치 변화·복잡한 시각 흐름에서 오류 증가10[측정/기록]
4. 옵션결정 ③ 세트·추가·맵기 등복잡한 선택사항에는 기본값·추천값 표기 권고11. 분식 옵션의 부담은 기록 없음[추론]
5. 담기·확인결정 ④ 더 담을지, 수량·삭제이전·처음으로 컨트롤, 오류 정정 방법 제공 요구11(지침이며 막힘 관찰 기록은 아님)[추론]
6. 부가 화면결정 ⑤ 포인트·쿠폰·추천 메뉴주문·결제 중 "구매와 무관한 멤버십 적립 유도 등 팝업창"12; 포인트 적립·사용 어려움 32.9%7[측정/기록]
7. 결제결정 ⑥ 결제 수단 → 카드 넣기현금·상품권 사용 어려움 37.3%, 잦은 기기 오류 31.0%7; 카드 삽입 방향 안내 권고11[측정/기록]
8. 완료번호표·수령 방법 이해공개 기록 없음미확인

이 표가 말하는 것 기록이 있는 막힘(3·6·7단계)은 '읽기'보다 '고르기·끼어드는 결정·결제 수단'에 있습니다 [측정/기록]. 결정 수를 줄이고 무관한 결정을 흐름 밖으로 빼는 것이 개입 지점이라고 봅니다 [추론]. 2·4·8단계는 자사 화면 없이는 판단할 수 없습니다.

여정 지도

시간 압박은 한 단계가 아니라 여정 전체에 깔려 있고, 막히는 순간 '직원 찾기'나 '포기'로 빠진다

점심시간 줄이라는 상황이 단계별 막힘과 어떻게 겹치는지 보려고 골랐습니다. 자사 관찰·로그가 없어 칸마다 공개 기록이 있는지, 추론인지, 미확인인지 색으로 구분했습니다. 감정 곡선은 그리지 않았습니다(측정 자료 없음).

이 그림이 말하는 것 막힘은 특정 화면 하나가 아니라 '결정이 끼어드는 단계 + 전 구간의 시간 압박'이 겹친 결과로 기록되어 있습니다 [측정/기록]7812. 화면 개편은 '막혀도 안 무너지는 흐름'을, 매장 운영은 '압박을 덜 느끼는 환경'을 맡아야 한다고 봅니다 [추론].

삼각검증

'조작 복잡'과 '시간 압박'은 서로 다른 세 종류 자료에서 수렴하고, '글씨'는 수렴하지만 순위가 낮다

본부 가설과 대안 가설이 한 조사에만 기대는지 확인하려고 골랐습니다. 설문(EV-01·03·04·07), 통계 모형 논문(EV-08), 사용성 연구·실험(EV-10·15), 전문가 평가(EV-12), 지침(EV-11·14)을 구분해 대조했습니다. EV-01과 EV-02는 같은 조사라 하나로 셉니다.

다섯 번의 왜

'직원을 부른다'에서 출발하면 원인 가지가 셋으로 갈라지고, 화면이 직접 손댈 수 있는 것은 그중 둘이다

매장 보고의 현상(포기·직원 호출)에서 출발해 원인 가설을 하나로 합치지 않고 가지로 남기려고 골랐습니다. 매장 보고 원문이 없어 출발 현상은 사용자 설명을 그대로 씁니다.

1

글씨 크기는 실재하는 막힘이지만, 혼자 끝내지 못하는 이유의 1순위는 아니다

한국소비자원 고령소비자 조사에서 '그림·글씨 작음'은 44.1%로 '복잡한 작동 방법' 51.4%보다 낮고4, 이용자 500명 조사에서는 60대 이상의 53%가 조작 어려움을 꼽은 반면 글씨 지적은 20%를 넘는 수준이었습니다3 [측정/기록]. 글씨를 키우는 것은 필요조건이되 충분조건이 아니라고 봅니다 [추론].

단, 두 조사 모두 기사 재인용이고 원문 문항·분모·복수응답 여부를 확인하지 못했습니다. 화면이 커지면 결정이 한 화면에 덜 들어가 흐름이 길어지는 부작용 가능성도 있으나 근거는 없습니다 [추측].

2

뒤의 줄은 '사람 수'가 아니라 '서둘러야 한다는 느낌'으로 작동한다

국내 60~70대 100명 연구에서 지각된 시간 압박이 사회적 불안(β=0.318)과 무력감(β=0.447)의 가장 큰 예측 요인이었지만 혼잡 인식 자체는 유의하지 않았습니다8. 뒷사람 눈치는 49%4, 44.9%(전 연령)7로 보고되고, 줄이 생기면 키오스크 이용자가 직원 주문보다 더 압박을 느낀다는 실험도 있습니다9 [측정/기록]. 압박을 줄이는 수단은 화면(시간제한 없음, 남은 단계 표시)과 매장(줄 방식, 좌석)에 나뉘어 있다고 봅니다 [추론].

단, Nam 외 연구는 매장 밖 시나리오 설문이고, Lu·Lee 실험은 고령자 한정이 아니며 논문 본문을 열지 못했습니다. 착석 효과(EV-15)는 프리프린트 초록만 확인했습니다.

3

기록된 막힘은 주문 중간에 '끼어드는 결정'(포인트·팝업·결제 수단)과 메뉴 찾기에 몰려 있다

전 연령 조사에서 현금·상품권 37.3%, 포인트 적립·사용 32.9%, 메뉴 찾기 28.6%, 상품 설명 부족 27.8%가 불편 이유로 꼽혔고7, 전문가 평가에서는 주문·결제 중 구매와 무관한 멤버십 팝업이 끼어드는 문제가 지적되었습니다12 [측정/기록]. 지침도 "한 화면에 하나의 과업"과 복잡한 선택의 기본값 표기를 요구합니다11 [측정/기록].

단, EV-07의 이유 항목은 60대 이상만 따로 나오지 않습니다. 분식 메뉴의 옵션 구조(맵기·사리·토핑·세트)가 얼마나 부담인지는 공개 자료가 없어 모릅니다.

4

막혔을 때 스스로 되돌아갈 길이 없으면, 직원 호출과 포기가 유일한 출구가 된다

사회적 불안은 직원 찾기(β=0.437)와 행동적 이탈(β=0.448)로 이어졌고8, 60대 이상의 37.0%가 주문을 중간에 포기한 경험이 있으며, '도와줄 직원 없음'도 23.0%가 꼽았습니다7 [측정/기록]. 지침은 이전·처음으로·직원 호출·오류 정정 경로를 요구합니다11. '혼자 끝내기'는 도움 버튼을 없애는 것이 아니라 혼자 회복할 길을 먼저 주고 도움은 안전망으로 두는 것이라고 봅니다 [추론].

단, '되돌리기가 없어서 불렀다'는 직접 관찰 기록은 공개 자료에 없습니다. 또 2026-01-28 전면 시행된 배리어프리 키오스크 의무에서 보조인력·호출벨 같은 대체 수단이 언급되므로13, 직원 호출 경로를 줄이는 방향은 법적 검토가 필요합니다 [추론].

5

처음 쓰는 사람에게는 '예측 가능함'이 '크게 보임'만큼 중요하다

고령자 사용성 연구에서 화면 배치가 바뀌거나 시각 흐름이 복잡하면 오류가 늘고, 세로 메뉴 배열과 같은 기능에 같은 색을 쓴 경우 오류가 적었으며, 테두리 없는 버튼은 버튼으로 인식되지 않았습니다10 [측정/기록]. 노화에 따른 단기기억·주의 저하14와 디지털 리터러시가 낮을수록 시선 찾기·과업이 느려진다는 결과16를 함께 보면, 처음 쓰는 사람에게는 화면마다 같은 자리·같은 모양이 중요하다고 봅니다 [추론].

단, EV-10·EV-16은 초록만 열어 표본 수와 오류 수를 확인하지 못했고, EV-10은 2019년 버거 주문 화면 기준입니다.

05

디자인 방향

디자인 원칙 생성

원칙 9개는 공개 지침(EV-11)과 고령자 연구·조사에서 반복된 막힘에서 나왔다 — 값과 모양은 레벨 2가 정한다

원칙은 화면의 동작·배치 규칙까지만 씁니다. 색·서체·문구·구체 치수는 정하지 않았고, 공개 지침의 최소값은 근거로만 인용합니다. 모든 원칙은 효과가 자사 매장에서 검증되지 않은 후보이며 채택·수정·반려는 회의에서 정합니다.

원칙조건과 행동근거예외·충돌
P1 한 화면, 한 결정주문 흐름의 각 화면은 결정 하나만 요구한다. 주문과 무관한 제안·광고·멤버십 적립 안내는 메뉴 선택~결제 사이에 띄우지 않고 결제 이후로 옮기거나 손님이 고를 때만 연다.지침 p.3211, 팝업 지적12, 포인트 32.9%7, 단순성↔무력감8 [추론]마케팅(멤버십 가입·추천 매출)과 충돌 — 본부 결정 필요. 단계 수가 늘어 보일 수 있음.
P2 기본값을 먼저 보여 주고, 바꿀 사람만 바꾼다옵션(세트·추가·맵기 등)은 가장 흔한 선택이 미리 골라진 상태로 보여 주고, 그대로 다음으로 갈 수 있게 한다.지침 p.5911, 최소 거래 단계 권고8 [추론]맵기·알레르기처럼 잘못 고르면 먹지 못하는 항목은 기본값으로 지나치지 않게 확인한다 [추측]. 무엇이 '흔한 선택'인지는 자사 판매 데이터 필요.
P3 기다리는 화면은 스스로 사라지지 않는다손님의 선택을 기다리는 화면에는 시간제한을 두지 않는다. 불가피하면 남은 시간을 보여 주고 연장할 수 있게 한다.지침 p.4011, 시간 압박8 [측정/기록]방치된 주문 정리(운영)와 충돌 — 현재 시간제한 유무 미확인.
P4 남은 단계를 늘 같은 자리에 보여 준다주문 흐름 내내 지금 몇 번째 단계인지와 남은 단계를 숫자와 글자로 같은 자리에 표시한다.지침 p.3411, 시간 압박8 [추론]단계 표시가 압박을 줄인다는 직접 근거는 없음 [추측].
P5 같은 일은 같은 자리, 같은 모양다음·이전·처음으로·직원 호출 버튼은 모든 화면에서 위치와 모양을 바꾸지 않는다. 단계 사이에 화면 배치 틀을 바꾸지 않는다. 버튼은 테두리나 면으로 '누를 수 있음'이 보이게 한다.고령자 사용성10, 지침 p.33·p.3911, 단기기억14 [측정/기록]브랜드 화면·프로모션 영역 배치와 충돌할 수 있음.
P6 메뉴는 숨기지 않고 세로로분류가 한 줄을 넘으면 옆으로 넘기기 대신 모두 보이게 여러 줄로 둔다. 메뉴는 세로 배열을 우선하고, 메뉴에는 그림과 이름을 함께 둔다.지침 p.3811, 세로 메뉴 오류 감소·그림+글 결합10, 메뉴 찾기 28.6%7 [측정/기록]메뉴 수가 많은 분식 특성상 한 화면에 다 들어가지 않을 수 있음 — 메뉴 수 미확인.
P7 결제 전에는 언제든 고칠 수 있다담은 메뉴는 결제 전 한 화면에서 확인·수량 변경·삭제할 수 있게 하고, 오류가 나면 원인과 고치는 방법을 같은 화면에서 안내한다.지침 p.39·p.4511, 회복 경로8 [추론]단계 하나가 추가됨(P1과 긴장) — 확인 화면을 결제 화면과 합칠지 레벨 2 검토.
P8 도움은 실패가 아니라 안전망직원 호출은 모든 화면 같은 자리에 두고, 눌러도 담은 주문이 지워지지 않게 한다. 혼자 회복하는 수단(P5·P7)을 먼저 보이게 하고 호출은 그 다음 출구로 둔다.지침 p.3911, 대체 수단 의무13, 직원 찾기 경로8 [추론]목표('직원 도움 없이')와 겉보기 충돌 — 성공 지표에서 '호출 0'을 목표로 삼으면 이 원칙과 충돌. 법적 대체 수단 요건은 법무 확인 필요.
P9 읽기 최소 기준은 지키되, 그것을 해결책으로 삼지 않는다글자 높이·명도 대비·누르는 영역 크기와 간격은 공개 지침 최소값 이상으로 맞추고, 크기 확대가 P1~P8을 깨지 않게 한다.지침 p.35·p.36 — 글자 높이 12mm 이상, 대비 4.5:1 이상, 컨트롤 한 변 12mm 이상·간격 2.5mm 이상11; 시각·손 변화14 [측정/기록]지침 값은 근거 인용이며 시안 값이 아님(레벨 2가 기기 실측 후 결정). 크기 확대로 한 화면 정보가 줄면 단계가 늘 수 있음.
DIR-01 · 미채택

흐름 먼저 — 주문 흐름 재구성 + 가독성 기준 동시 충족

개편 범위를 '화면 키우기'가 아닌 주문 흐름 전체(단계·결정·끼어드는 화면·되돌리기·도움)로 잡고, 모든 손님이 같은 한 흐름을 쓰되 처음 쓰는 60대 이상이 막히지 않는 것을 기준으로 삼으면 혼자 끝내는 비율이 오를 것이다 [추측]

DIR-02 · 미채택

압박 덜기 — 화면과 매장 운영을 함께 바꾸기

DIR-01의 화면 개편에 더해, 점심시간 줄 운영(여러 기기에 하나의 줄 등)·좌석·직원 호출 응대 방식을 함께 바꾸면 '서둘러야 한다는 느낌' 자체가 줄어 포기가 줄 것이다 [추측]

왜
인사이트 2·4, HMW 2·4. H3(느낀 시간 압박)는 화면만으로는 일부만 다룰 수 있다.
무엇을
주문 화면(P3·P4 중심) + 매장 주문 공간 운영 지침.
누구에게
처음 쓰는 60대 이상 손님, 그리고 매장 직원(호출 응대).
어떤 순서로
① 화면의 시간제한 제거·남은 단계 표시 → ② 가맹점 줄 방식·기기 배치 현황 파악 → ③ 시범 매장 운영 변경.
어떤 정보를
화면: 남은 단계, 호출 시 주문 유지 안내. 매장: 줄 서는 위치 안내(내용은 레벨 2).

잃는 것
UX팀 단독으로 결정할 수 없음(가맹 운영·점포 공간), 매장별 편차, 비용.

별도 쉬운 경로 — 시작 화면에서 고르는 '쉬운 주문'

시작 화면에서 고를 수 있는 단순 경로(적은 메뉴·기본 옵션·큰 표시)를 따로 두면 처음 쓰는 고령 손님이 끝까지 갈 수 있을 것이다 [추측]

왜
인사이트 1·3, HMW 1·3. 국내에 고령자용 ATM·'디지털 약자' 키오스크 개발 사례가 있다2.

어떤 순서로
DIR-01 감사 뒤, 기본 흐름만으로 부족할 때 검토.
어떤 정보를
대표 메뉴 중심(구성 기준은 판매 데이터 필요).

공개 자료에서 이런 별도 경로의 효과 결과를 찾지 못함 — 근거가 가장 약한 후보.

렌즈별 반증 질문

  • 가독성: 자사 기기에서 글자 높이·대비가 이미 지침 최소값 이상인데도 호출이 많다면 이 렌즈는 약해진다.
  • 흐름: 자사 화면의 결정 수·팝업이 이미 적다면 이 렌즈는 약해진다.
  • 압박: 줄이 없는 시간대에도 60대 이상의 호출 비율이 같다면 이 렌즈는 약해진다.
  • 회복: 호출 직전 화면이 특정 단계에 몰리지 않고 시작 화면에 몰린다면 '되돌리기'보다 '시작 이해'가 문제다.
