## 발견한 실행 결함 — Issue #36

글꼴 비교 renderer는 fixture의 task ID와 variant label을 이미지 경로에 그대로 넣었다.
임시 fixture의 task ID를 선택한 출력 폴더 밖의 절대 경로로 바꾸고 실제 로컬 서체로 실행하면,
그곳에 `A.png`가 생성된 다음 `relative_to(output)`에서 ValueError/종료 1이 발생했다.
실패 종료가 파일 무변경을 뜻하지 않았다. 중복 ID/label도 동일 이미지 파일을 덮어쓸 수 있었다.

수정은 이름을 단일 경로 요소로 검사하고 절대·부모·Windows 경로와 대소문자를 무시한
중복 이름을 거부한다. 각 A/B 이미지의 목적지를 폰트 읽기와 디렉터리 생성 전에 해석하여,
출력 하위의 기존 링크가 외부로 이어지면 거부한다. 정상 fixture·BASIC 렌더 계약은 유지한다.

회귀는 잘못된 ID/label·중복, 실제 CLI의 외부 PNG 무생성, 기존 출력 링크의 외부 파일 보존을
검사한다. 수정 전 새 회귀가 실패했고 수정 후 글꼴 시험 6개가 모두 통과했다.
경로 확인 뒤 다른 프로세스가 경로를 바꾸는 동시 변경은 보호 범위 밖이다.
