## 새 적용 사례: 푸투라의 기하학적 불순성에 관해

공식 출처: https://www.sulki-min.com/wp/on-the-geometric-impurity-of-futura-kr/

실제로 관찰한 공개 GIF는 709×992px, 1프레임이다. 공식 설명은 F 두 개의 회전·중첩을 지지한다. 정지 화면을180도 회전 관계로 모델링했지만 실제 편집 파일의 회전값을 확인한 것은 아니다.

손으로 정의한 직선형 F 하나와 그 회전 사본의 합집합을 어두운 색, 교집합을 노랑으로 출력했다. 래스터 윤곽 추적이나 노란 조각의 개별 좌표 배치는 하지 않았다. Windows Fonts에서 Futura 파일을 찾지 못해 구조적 대체 자형을 썼으며 폰트 복구가 아니다. 원본 이미지·폰트·결과 이미지는 이 PR에 재배포하지 않는다.

기본 모델의 동일 획/중앙 배치는 임의의 수학적 대조군이지 Futura의 실제 설계 과정이라는 주장이 아니다. 네 기하 보정은 공유 F 하나에 적용되어 회전 사본에도 함께 반영된다. 사본별 독립 이동이나 비등방 확대는 사용하지 않았다. 보정 이유·범위·효과는 아래와 같다.

- 상단 두께: 수직 줄기보다 얇게 관찰됨. 공유 F와 회전 사본에 적용, 위·아래 노란 끝 높이가108→102로 바뀜.
- 중간 시작: 완전 중앙보다 위에 관찰됨. 공유 F에 적용, 교집합의 단차를 만듦.
- 중간 두께: 수직 줄기와 다르게 관찰됨. 공유 F에 적용, 중앙 띠의 폭과 교차 높이가 바뀜.
- 중간 폭: 상단보다9px 짧게 관찰됨. 공유 F에 적용, 반대편9px 노출 구간을 만듦.
- 색·자산 대체: 화면 비교에만 적용. 실제 잉크색·원본 글리프 복구를 보증하지 않음.
