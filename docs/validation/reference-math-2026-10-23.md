# 문서 연결 산술 검사 보강 (2026-10-23)

대상: PR #22의 기존 `ed0be0b` 검사 및 PR #6의 합성 레퍼런스 사례.
macOS arm64, Python 3.12.14에서 확인했다.

- 수정 전 문서의 정규화 결과를 `9.10, 9.35, 9.60`으로 바꿔도
  `check_reference_math()`가 통과함을 실제 검사 함수로 재현했다.
- 사례의 입력과 기대 결과를 RA-1 표 한 곳에 모았다. 검사는 이 표를 읽어
  정규화 좌표, 인접 차분, 중앙값 피치, 모델 잔차를 다시 계산한다.
- 잘못된 정규화·차분·피치·잔차·0 너비를 거부하고, 일관되게 바꾼 입력과
  결과는 허용하는 회귀 시험을 추가했다. 예전 숫자를 암기하는 검사로 대체하지 않았다.
- 기존 opt-in 회귀 4건과 새 산술 회귀 7건, 총 11건이 통과했다.
  전체 구조 검사와 `git diff --check`도 통과했다.

이 시험은 문서의 합성 산술을 확인한다. 실제 이미지 역추정·모델 라우팅·디자인
도구 적용·판독성은 검증하지 않는다. 기존 A~H 정책값도 변경하지 않았다.
