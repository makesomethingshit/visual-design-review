# 다섯 번의 왜

**필수 입력:** 기록으로 확인된 현상 또는 과업 문제, 영향, 관련 시점·조건, 근거 위치
**기대 출력:** 현상에서 출발해 최대 다섯 단계로 이어진 원인 가설의 가지, 각 근거·공백·확인 질문

## 절차

- 먼저 관찰된 현상과 영향만 한 문장으로 쓰고 문제의 원인을 미리 확정하지 않는다.
- 각 “왜?”에 대해 기록으로 뒷받침되는 답과 대안 답을 가지로 적고 근거 위치를 붙인다.
- 근거가 끊기거나 답이 여러 개면 더 묻지 않고 가설, 미상, 확인 질문으로 표시한다.
- 가지별 개입 가능한 조건과 반례를 비교하되 하나의 뿌리 원인으로 합치지 않는다.

완료/한계: 원인 탐색 가설의 정리이며 단일 근본 원인이나 인과관계를 입증하지 않는다.
