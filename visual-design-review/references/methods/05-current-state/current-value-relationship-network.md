# 현재 가치 관계망

**필수 입력:** 기록된 행위자, 제공물·활동, 가치 주장, 교환·의존 관계, 성과·비용 단서
**기대 출력:** 현재 기록상 가치가 누구에게 어떻게 제안·전달·교환되는지와 근거·공백을 연결한 관계망

## 절차

- 자료에서 행위자별로 중요하다고 표현된 결과와 제공물·활동을 추출한다.
- 가치 주장, 기대되는 교환, 의존 관계를 별도 관계로 표시하고 해당 기록을 붙인다.
- 실제로 관찰된 성과와 주장·기대를 구분하며 비용·손실·배제 단서를 함께 적는다.
- 관계의 충돌, 미상인 수혜자·부담자, 사람의 확인이 필요한 해석을 별도 목록으로 남긴다.

완료/한계: 기록된 현재 가치 관계의 모델이며 가치의 실제 크기·공정성·효과를 판정하지 않는다.
