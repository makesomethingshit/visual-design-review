# 제공물·활동·문화 지도

**필수 입력:** 기록된 제공물, 관련 활동, 규범·관습·상징·가치 표현, 사용자·조직 맥락
**기대 출력:** 제공물·활동·문화 요소의 관계와 긴장, 근거, 미확인 항목을 함께 보여주는 지도

## 절차

- 자료에서 제공물과 사용·운영 활동, 문화적 표현을 각각 추출해 세 영역에 배치한다.
- 각 제공물이 어떤 활동과 연결되고 어떤 규범·관습 속에서 해석되는지 근거와 함께 잇는다.
- 반복되는 기대와 충돌하는 표현을 기록 사실과 해석 가설로 분리한다.
- 문화 요소를 단일한 의미로 일반화하지 않고 다른 해석과 확인 질문을 남긴다.

완료/한계: 제공된 기록의 제공물·활동·문화 관계를 비교하는 지도이며 문화 집단 전체를 대표하지 않는다.
