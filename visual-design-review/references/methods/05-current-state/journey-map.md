# 여정 지도

**필수 입력:** 기록에서 확인 가능한 대상 사용자, 시간·단계 순서, 접점, 행동, 목표, 장애 단서
**기대 출력:** 한 대상의 단계별 행동·접점·장애·근거와 미확인 지점을 나란히 비교한 여정

## 절차

- 여정의 시작·종료 조건과 대상 사용자를 기록에서 명시한다.
- 시간 순서대로 단계와 접점을 배치하고 각 단계의 행동·목표·장애를 원문 위치와 함께 적는다.
- 단계 사이의 전환, 대기, 반복, 이탈을 기록과 추론으로 구분한다.
- 여러 기록이 다르게 말하면 경로를 합치지 않고 대안 경로와 빈칸을 병기한다.

완료/한계: 제공되거나 공개된 기록의 경로만 정리하며 실제 사용자의 감정·행동을 새로 확인하지 않는다.
