# 활동 네트워크

**필수 입력:** 기록에 나타난 활동, 참여자, 선후·동시 수행 단서, 산출물, 활동 간 연결
**기대 출력:** 활동을 노드로, 참여·선후·공유 산출물을 관계로 표시한 네트워크와 근거 목록

## 절차

- 기록에서 활동을 동사 중심의 짧은 단위로 추출하고 수행자와 자료 위치를 붙인다.
- 선행·동시·반복·공유 산출물 관계를 서로 다른 선으로 표시한다.
- 참여자가 바뀌는 지점과 활동이 겹치거나 끊기는 지점을 기록과 추론으로 구분한다.
- 관계가 없는 것인지 기록이 없는 것인지 분리해 미확인 목록을 만든다.

완료/한계: 기록된 활동의 연결을 보여주는 네트워크이며 실제 빈도·중요도·인과를 측정하지 않는다.
