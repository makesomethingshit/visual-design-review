# 극단·일반 사용자 비교 자료 조사

**필수 입력:** 기존 사용자 기록, 극단·일반 분류 기준과 근거, 사례 메타데이터, 비교 질문.

**기대 출력:** 두 집단의 목표·행동·제약 차이와 공통 패턴, 분류 한계와 근거 연결.

**절차**

1. 기존 자료에서 사용된 극단·일반 분류 기준과 사례 수를 먼저 고정한다.
2. 동일한 비교 축으로 목표, 행동, 환경, 우회 방법을 추출해 사례표를 만든다.
3. 집단 간 차이가 사용자 특성인지 맥락·기록 방식 차이인지 대조한다.
4. 공통점·대조점·분류 밖 사례를 원기록 위치와 함께 보고한다.

**자료 추적:** 결과에 집단 분류 근거·사례 ID·원기록 페이지/타임코드를 연결한다.

**누락·편향 메모:** 극단·일반 라벨 자체가 선택과 해석의 산물일 수 있다. 작은 집단이나 특정 행동을 전체 사용자 분포로 일반화하지 않고 분류 밖 사례를 버리지 않는다.
