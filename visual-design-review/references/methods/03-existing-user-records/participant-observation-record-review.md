# 참여 관찰 기록 조사

**필수 입력:** 기존 참여 관찰 현장 기록·영상·사진·메모, 활동 맥락, 기록자와 기록 시점.

**기대 출력:** 활동 순서와 맥락에 근거한 행동·전략·상호작용 패턴, 예외와 기록 공백.

**절차**

1. 기록에서 관찰된 행동·직접 발화·기록자의 해석을 세 층으로 분리한다.
2. 활동 순서, 도구 사용, 주변 사람과의 상호작용, 중단·우회를 시간순으로 정리한다.
3. 장소·업무·사례별 패턴을 비교하고 참여로 인해 달라졌을 가능성을 별도 표시한다.
4. 각 발견을 기록 위치에 연결하고 관찰되지 않은 단계와 대안 설명을 남긴다.

**자료 추적:** 관찰 기록 ID·파일명·타임코드/페이지·장소 메타데이터를 결과에 붙인다.

**누락·편향 메모:** 기록자의 참여와 선택적 기록이 행동을 바꿀 수 있다. 기록되지 않은 행동을 하지 않았다고 보지 않으며, 특정 현장·시간의 사례를 일상 전체로 확대하지 않는다.
