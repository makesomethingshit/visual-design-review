# 심층 인터뷰 기록 조사

**필수 입력:** 기존 심층 인터뷰 녹취·요약·메모, 질문지 버전, 세션 식별자, 기록일과 분석 질문.

**기대 출력:** 사례별 근거가 연결된 요구·동기·행동 패턴, 반례, 공백과 해석 한계.

**절차**

1. 세션별 기록을 목록화하고 질문지 버전·기록 범위·누락 구간을 표시한다.
2. 발화에서 사실 진술, 해석, 요구, 가설을 분리해 동일한 코드로 표시한다.
3. 사례 간 공통점·차이·반례를 비교하고, 주장마다 발화 위치를 연결한다.
4. 반복 패턴과 단일 사례를 구분해 요약하고 추가 확인이 필요한 공백을 남긴다.

**자료 추적:** 각 결과에 원기록 파일·세션 ID·페이지/타임코드를 연결한다.

**누락·편향 메모:** 녹취되지 않은 발화와 누락 회차는 미상으로 둔다. 자발적 참여자·특정 문제를 가진 사례가 전체 사용자를 대표한다고 일반화하지 않는다.
