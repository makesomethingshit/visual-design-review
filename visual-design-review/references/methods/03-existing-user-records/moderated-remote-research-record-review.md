# 진행자 동반 원격 조사 기록 검토

**필수 입력:** 기존 진행자 동반 원격 세션 녹화·녹취·채팅, 진행자 가이드, 과업 버전, 세션 ID와 기술 상태.

**기대 출력:** 과업 수행·발화·진행자 개입·기술 조건의 관계, 세션 간 패턴과 누락.

**절차**

1. 세션을 과업 단계별로 나누고 참가자 행동, 발화, 진행자 질문, 기술 중단을 별도 표기한다.
2. 자발적 반응과 질문에 대한 반응을 구분해 코드화한다.
3. 세션·환경·과업 버전별 완료·혼란·우회 패턴을 비교한다.
4. 발견을 녹화 타임코드·채팅 메시지·과업 ID에 연결하고 끊긴 구간을 공백으로 남긴다.

**자료 추적:** 결과에 세션 ID·진행자 가이드 버전·과업 ID·타임코드를 연결한다.

**누락·편향 메모:** 진행자의 프레이밍과 원격 접속·기기 조건이 응답을 바꿀 수 있다. 기술 문제로 누락된 행동을 실패로 단정하지 않고 온라인 참여가 가능한 표본으로 한정한다.
