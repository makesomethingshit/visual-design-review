# 맥락 인터뷰 기록 조사

**필수 입력:** 기존 맥락 인터뷰 녹취·현장 메모, 작업·환경 정보, 세션 식별자, 기록일과 분석 질문.

**기대 출력:** 작업 맥락과 연결된 행동·제약·우회 방법의 사례 비교, 근거와 공백.

**절차**

1. 각 발화를 작업 단계, 장소·도구, 당시 목표와 연결해 시간순으로 정리한다.
2. 말로 설명한 이유와 기록에서 확인되는 행동·환경 단서를 분리한다.
3. 환경별 제약·우회 방법·중단 지점을 비교하고 예외 사례를 표시한다.
4. 해석마다 발화와 맥락 메모를 연결하고 관찰되지 않은 조건을 공백으로 남긴다.

**자료 추적:** 결과 항목에 녹취 파일·세션 ID·발화 타임코드와 맥락 메모 위치를 남긴다.

**누락·편향 메모:** 인터뷰 중 언급되지 않은 작업 단계는 부재로 단정하지 않는다. 특정 장소·시간대·업무 유형에 치우친 기록은 다른 맥락에 일반화하지 않는다.
