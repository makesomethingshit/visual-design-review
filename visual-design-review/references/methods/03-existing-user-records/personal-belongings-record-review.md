# 소지품 조사 기록 검토

**필수 입력:** 기존 소지품 목록·사진·사용 일지·포장/보관 기록, 물품·사용 맥락, 사례·기록일.

**기대 출력:** 소지품의 역할·선택·사용 방식과 상황별 패턴, 명시된 사용과 기록 근거의 차이.

**절차**

1. 물품 ID, 사진·목록·일지의 출처와 사용·보관 상황을 한 기록으로 묶는다.
2. 보이는 물품, 사용이 기록된 행동, 소유자 설명을 분리해 코딩한다.
3. 물품의 역할·대체·우회 사용을 상황·사례별로 비교한다.
4. 해석을 물품 ID·이미지/일지 위치에 연결하고 기록되지 않은 용도는 추정하지 않는다.

**자료 추적:** 결과에 물품 ID·사진/목록 파일·일지 페이지·기록일을 연결한다.

**누락·편향 메모:** 보이거나 자발적으로 제공된 물품만 남고 사적·폐기·대체품은 빠질 수 있다. 소지 자체를 사용이나 선호의 증거로 바꾸지 않는다.
