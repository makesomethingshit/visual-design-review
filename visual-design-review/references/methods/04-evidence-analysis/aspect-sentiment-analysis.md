# 측면별 감성 분석

**필수 입력:** 대상별 텍스트·기존 반응 기록, 분석할 측면 목록 또는 도출 규칙, 자료 ID·위치·시점

**기대 출력:** 측면별 반응 방향·표현 강도·대표 인용·상충 사례와 근거 추적표

## 절차

1. 기록에서 대상과 측면을 분리하고, 한 문장에 여러 측면이 있으면 각각의 근거 범위를 표시한다.
2. 각 측면의 반응을 긍정·부정·중립·판정 불가로 분류하고, 명시된 표현과 분석자의 해석을 구분한다.
3. 반복되는 불만·만족 표현을 묶되 표현 수를 사용자 수나 선호도의 비율로 바꾸지 않는다.
4. 측면별 대표 원문, 반대 사례, 자료 시점과 `관찰/추론/추측` 상태를 표로 제출한다.

**완료·한계:** 모든 측면과 판정 불가 항목을 포함한다; 기존 기록의 표현을 분석할 뿐 감정의 실제 원인·전체 사용자 분포를 검증하지 않으며 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
