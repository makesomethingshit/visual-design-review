# 관찰 데이터 질의

**필수 입력:** 사용자 관찰 데이터베이스 또는 표, 질의 질문·필터·기간·대상 조건, 결과 판정 기준

**기대 출력:** 재현 가능한 질의 조건, 일치·불일치·누락 레코드와 원문 위치·해석 범위

## 절차

1. 질문을 필드 조건과 반환할 필드로 바꾸고 날짜·대상·상황의 단위와 포함 경계를 고정한다.
2. 질의를 실행해 일치 레코드와 제외·미상 레코드를 분리하고, 각 결과에 관찰 ID와 원문 위치를 붙인다.
3. 결과를 원자료와 대조해 중복·상충·빈 필드·코드 오류를 표시하며 행 수를 사용자 수나 발생률로 과장하지 않는다.
4. 질의 버전·실행 시점·필터·결과 요약을 저장하고, 질문에 답하지 못한 이유와 다음 확인 조건을 적는다.

**완료·한계:** 같은 조건으로 결과를 다시 찾을 수 있고 제외·미상도 남는다; 질의 결과는 저장된 기록의 범위에만 적용되며 누락되지 않은 현실이나 인과를 보장하지 않고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
