# 비대칭 군집 매트릭스

**필수 입력:** 방향이 있는 출발·도착 항목, 관계·영향·의존 기준, 항목·관계별 근거 ID·원문 위치

**기대 출력:** 방향별 군집 매트릭스, 출발-도착 관계·미연결·상충·근거 범위 표

## 절차

1. 행을 출발 항목, 열을 도착 항목으로 정하고 `A→B`와 `B→A`가 다른 관계임을 기록한다.
2. 각 셀에 관찰된 방향·관계 유형·근거를 입력하고, 방향이 자료에 명시되지 않으면 미확인으로 둔다.
3. 공통 도착·공통 출발·상호 관계·일방 관계를 군집화하되 위치나 연결 수만으로 영향력을 판단하지 않는다.
4. 역방향 셀과 빈 셀을 재검토해 누락·반례·인과로 과장될 표현을 고치고 `관계 → 근거 → 한계`로 제출한다.

**완료·한계:** 모든 방향 셀과 미연결·미확인 상태를 구분한다; 방향성 기록은 관계의 관찰·표현 방식만 보여주며 인과, 우선순위, 실제 영향의 크기를 검증하지 않고 기존 제공 자료·공개 기록만 사용하는 Level 1 실무 적응안이다.
