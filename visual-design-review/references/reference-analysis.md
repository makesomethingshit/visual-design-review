# Reference analysis: 조형 관계의 증거 기반 역분석

**범위:** 시각디자인 레퍼런스의 조형·배치·서체·색·정보 관계를 가능한 한
정량적으로 해체하고, 관찰과 일치하는 **재현 가능한 모델**을 제안한다.
이미지 분석·레이어 분리 엔진을 구현하는 문서가 아니다.

## 절차

1. **입력 확인:** 편집 원본(Figma/SVG 등)인지 PDF인지 래스터/스캔인지,
   치수·해상도·서체·레이어 등 확인 가능한 정보가 무엇인지 명시한다.
2. **객체/영역 분리:** 텍스트/이미지/벡터/색면·반복 요소·캡션 관계를 목록화.
   겹친 부분, 가려진 영역, 불명확한 그룹은 추정으로 남긴다.
3. **측정과 정규화:** 관찰 가능한 좌표, bbox, 기준선, 간격, 색채를 취득한다.
   페이지 폭 W와 객체 x,w가 확인되면 x/W, w/W와 같은 상대 비율을 계산한다.
   실제 파일 없이 스크린샷만 있다면 **픽셀 기반 근사치**임을 명시한다.
4. **가설 생성:** 가능한 그리드 피치, 정렬축, 비례 관계, 타이포 위계, 색 관계
   등의 **경쟁 모델**을 적는다. 같은 픽셀을 설명하는 여러 제작 구조를 허용한다.
5. **재구성 검증 계획:** 명세로 재렌더링할 수 있다면 개별 요소의 위치·크기·
   그룹·줄바꿈·색차 및 픽셀 차이를 원본과 비교한다. 실행하지 않았으면
   오차를 숫자로 꾸미지 않고 '미검증'으로 기록한다.
6. **일반화:** 원본 한 장의 측정치가 보편 디자인 법칙은 아니다.
   새로운 판형/문자열·비슷한 다른 작업에서 관계가 유지되는지 따로 시험한다.

## 증거 등급

| 등급 | 허용하는 주장 | 금지 |
| --- | --- | --- |
| **Verified source** | 원본 편집 객체의 위치·색·폰트 ID 등 직접 조회한 필드 | 조회하지 않은 저자의 의도/제작 과정 확정 |
| **Measured raster** | 확인한 해상도의 이미지 픽셀·분할 결과 | 실제 mm/pt, 출력 ICC 프로파일, 폰트명 단정 |
| **Estimated** | 경계 모호성·압축·안티앨리어싱 등이 있는 근사치와 오차 가능성 | 불확실한 값을 정밀 측정값으로 표현 |
| **Inferred model** | 관찰을 설명하는 그리드·비례·계층 가설 | 같은 결과를 원래 제작 규칙으로 확정 |
| **Unverified** | 추가로 필요한 자료와 확인 방법 | 렌더·실물 검증을 했다고 주장 |

측정값의 신뢰도, 렌더링 차이, 레이어 중복/누락, 폰트 후보 및 가려진 영역의 불확실성은
**서로 다른 항목으로 기록**한다. 하나의 임의 가중치 '디자인 점수'로 합치지 않는다.

## 최소 분석 산출물

- 입력/측정 방법: 파일 유형, 해상도와 물리 치수 확인 여부, 관찰 영역
- 관측 요소: 식별자, bbox/비율, 계층·겹침, 문자/컬러, 확인 상태
- 추론된 관계: 공식 또는 가설, 참조 변수, 적용 조건 및 경쟁 모델
- 재구성: 재현하기 위한 파라미터, 필요한 도구, 실제 검증 여부와 항목별 오차
- 미결정: 특정 폰트, 숨은 레이어, 원저자 의도, 재현 불가 영역 등

## 연구 배경 (분석 절차의 참고, 코드·데이터 복제 없음)

- [ReDesign (2026)](https://arxiv.org/html/2607.25565):
  의미 있는 편집 가능 계층 복원, 단계별 수용/거부/재시도의 근거.
- [Vector Layout Transfer (2023)](https://arxiv.org/html/2309.11635v1):
  위치뿐 아니라 레이아웃 관계를 추출하여 다른 구조로 전달하는 문제.
- [Re-typograph (2015)](https://doi.org/10.1117/12.2075813):
  서로 다른 서체 파라미터가 유사한 출력이 될 수 있다는 역문제의 한계.
- [Reverse-engineering information presentations (2023)](https://link.springer.com/article/10.1007/s44267-023-00010-1):
  시각 요소 간 계층적 그룹 관계 복원.
