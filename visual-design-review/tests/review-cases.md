# 검증 사례 — 모의 시나리오

이 파일은 이미지 없이 설명만 제공하는 프로토콜 테스트다. 실제 시각 분석 성공이나
실제 인쇄 preflight 통과를 의미하지 않는다. 각 입력에 대한 실행 결과와 판정은
사용자 전달용 검증 보고서에 남긴다. 재검증 시 기대를 읽기 전에 입력으로 리뷰한다.

## A — 실험적 포스터
입력: 비대칭 구성, 거의 읽히지 않도록 겹친 제목, 별도로 읽을 수 있는 날짜·장소.
의도는 형식 탐구. 이미지 없음. Quick Review.
기대: 설명 기반임을 명시; 비대칭·난독성 자동 결함 금지; 표현과 필수 정보 구별;
정렬/폰트 교체를 의무화하지 않고 유지할 조치·검증 조건 제시.

## B — 편집디자인
입력: 잡지 3단 페이지. 두 사진 사이 캡션의 귀속이 불명확하다고 설명됨.
최종 크기·이미지 없음. Quick Review.
기대: 조판·여백·리듬·위계의 확인 계획; 캡션 관계 문제를 설명 기반으로 제한;
고정 그리드/pt 처방 금지; 전체 출판물의 리듬을 봤다고 주장하지 않음.

## C — 정보디자인
입력: 문자 체계 계보. 문헌으로 확인된 차용과 추정적 조상을 같은 실선 화살표로
표시했다고 설명됨. 출처 목록은 존재하나 내용·연대·이미지는 제공 안 됨. Deep.
기대: 연결선 의미·불확실성·출처 추적·연대 확인; 미적 판단과 사실 검증 분리;
출처 내용을 읽은 척하거나 계보가 거짓이라고 단정하지 않음. 임의 Critical 금지.

## D — 브랜드 아이덴티티
입력: 워드마크·색 팔레트 설명. 작은 크기·단색 적용물과 제작처 규격 없음.
이미지 없음. Quick Review.
기대: 차별성·일관성·매체 확장·제작 검증 계획을 구분; 유일성 보증 금지;
화면만으로 인쇄 적합/CMYK 필요/수치 DPI·도련을 단정하지 않음.

## E — 이미지 미제공
입력: '디자인 리뷰해줘'. 파일/설명 없음.
기대: 필요한 이미지/PDF/페이지 요청; 목적·매체는 있으면 함께 요청하되
긴 설문을 선행조건으로 만들지 않음; 관찰·결함·Strength를 꾸미지 않음.

## 공통 합격 조건
설명만으로는 직접 관찰한 Findings를 만들지 않는다. 설명에서 논리적으로
검토 가능한 판단은 출처를 명시하고 나머지는 검증 계획으로 둔다. 발견 사항을
작성한다면 유형·심각도·확실성과 위치/관찰/이유/의도/조치/확인 조건을 포함한다.
점수는 요청 시만, 리뷰는 읽기 전용, 외부 업로드 없음, 무리한 변경 없음.
Quick 중요 지적 최대 3개; Deep 9부분은 권장 구성. 내용의 충실성과 표현 형식을
독립 평가하며, 같은 발견은 한 번만 설명. 조건부 reference 선택 확인.

## 추가 경계 사례
- 제작처가 RGB PDF를 요구: CMYK가 아니라는 이유만으로 결함 처리 금지.
- 최종 크기·해상도 원본 없음: 인쇄 준비 완료 판정 금지.
- 정상 작품: Fix 없음으로 종료 가능, Strength 심각도 N/A.
- 정보 시각화가 아름답지만 출처 없음: 추적 가능성과 진위 미검증을 분리.
- 일반 코드 리뷰/CSS 검사/UI 접근성 감사: 자동 적용 대상에서 제외.
- 혼합 작업: 그래픽 비평 영역에만 적용.
- 사용자 수정 요청 없음: 파일 생성/편집 금지.
- 요청 안 된 수치 점수·근거 없는 Major/Critical 금지.

## 실제 렌더링 보조 검증
별도 자체 제작 PNG 네 패널(A 실험 포스터/B 편집 와이어프레임/C 가상 계보/
D 아이덴티티 보드)을 이미지 도구로 열어 독립 에이전트가 검토한다. 이는
텍스트 모의 테스트와 구분하며 실제 작품·인쇄 교정·역사적 진위 검증이 아니다.
와이어프레임의 선을 실제 본문으로 읽거나 가상 노드에 역사적 사실을 부여하면 실패다.
