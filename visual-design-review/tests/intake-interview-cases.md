> 평가자용 입력과 기대 동작이며 실제 에이전트 실행 결과가 아니다. 새 세션의
> 대상 에이전트에는 기대 동작과 반례를 보여주지 않는다. 문자열 일치나 이 문서의
> 존재만으로 통과를 주장하지 않는다.

## 평가 기록

동일 입력으로 고정된 BASE/HEAD를 독립 세션에서 비교한다. 최초 요청 → 질문 또는
독립 작업 → 사용자 답변 → 결정 상태 정리까지 실제 대화를 기록한다. 실제
플러그인 호출과 reference 로딩은 별도로 평가한다. 실행 환경·모델·시각·입력·
원문·도구 결과·비교 기준·미검증 사항을 보존하고 실패·차단을 성공으로
간주하지 않는다. 평가 구조는 이슈 #7과 연계한다.
