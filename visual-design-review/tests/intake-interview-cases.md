# 새 디자인 과제 인터뷰 — 수동 행동 시나리오

> 입력과 기대 동작이며 실제 에이전트 실행 결과가 아니다. 각 사례는 새 세션에서
> 입력만 제공하고 응답과 도구 실행을 기록해 평가한다. 기대 항목의 존재나
> 문자열 일치만으로 통과를 주장하지 않는다.

## 평가 기록

동일 입력으로 기준 스킬과 변경 스킬을 분리 실행한다. 최초 요청 → 질문 또는
독립 작업 → 사용자 답변 → 결정 상태 정리까지 실제 대화를 기록한다. 가능하면
실제 플러그인 호출 및 reference 로딩도 별도로 확인한다. 실행 환경, 모델,
시각, 입력, 원문, 도구 결과, 비교 기준, 미검증 사항을 보존하고 실패·차단을
성공으로 간주하지 않는다. 평가 구조는 이슈 #7과 연계한다.
